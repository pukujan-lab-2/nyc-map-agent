## Problem

On a phone in a noisy place (street, platform), voice input fails to hear the user. On Brave (which blocks the browser's speech recognizer) the app records one turn and sends it to Whisper. It decides the turn is over when loudness stays under a fixed 0.02 level for 1.3 s. Steady background noise sits above that level, so the turn never ends, runs to the 20 s cap, and Whisper receives a clip that is mostly noise.

## What changes

- `src/lib/voice/serverStt.ts`: the recorder tracks the room's background level (`nextFloor`) and counts a frame as speech only when it is 2.5x above it (`speechLevel`), never below the old 0.02 bar. Steady noise is absorbed within a few seconds; a voice over it still counts.
- `src/lib/voice/serverStt.test.ts`: three tests (bar never drops below the quiet-room level, steady noise stops counting as speech while a voice still does, the level follows a quieter room back down).

## How to verify

- `npx vitest run src/lib/voice`: 21 tests pass (checked locally).
- On a phone in a noisy place: say a question, stop, and the turn should end about 1.3 s later instead of at 20 s.

## Unchanged

Quiet-room behavior, the server `/api/stt` call, echo cancellation and noise suppression settings, and the tap-to-stop button.

Not verified on a real phone yet.
