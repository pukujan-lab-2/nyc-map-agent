After about 15 exchanges with the assistant, every new question failed. The app sent the whole conversation, and the server refuses more than 30 messages.

**What changes**
- `recentTurns` in `src/features/agent/chatWindow.ts` sends only the latest 30 messages. It always starts on a question, so the model never sees an answer without the question it answered.
- `AgentOverlay` uses it. The limit is one shared constant, `MAX_MESSAGES`, in `schema.ts`, so the app and the server can't drift apart.

**How to verify:** `npx vitest run src/features/agent/chatWindow.test.ts` builds a 41-message chat and checks that what is sent passes the server's own request check. In the app, ask 16 questions in a row; the last one gets an answer.

**What stays the same:** the conversation on screen keeps everything; only what is sent is trimmed. The assistant chunk is 23.84 of its 24 kB limit.
