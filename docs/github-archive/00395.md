Someone who opens the live site today gets the old data dashboard: a search box, a row of view buttons and analytics panels. The owner has agreed a different first screen. It is a clean map with a chat bar that is never hidden, four task buttons (Restroom, My train, Plan trip, Find exit) and every other control one tap away. This pull request ships that design, plus the realignment work that was waiting in separate PRs.

## What changes

1. **The chat-first home is the default.** You can type, dictate, or tap the big waveform for hands-free. The new home sits behind the `agentHome` flag, which is now on; `?flags=-agentHome` still shows the old screen.
2. **One swipeable menu row at the top left.** It holds My day, Layers, Filters, Data, City data and Settings. The open menu sits leftmost as a labelled pill, and the others trail off smaller and fainter. Each menu opens as a dropdown over the map, one at a time, so the map stays visible.
3. **My day** shows today's notices for your usual lines, your rides, and the last five trips you looked up. It never suggests food or shops, and never tells you when to leave.
4. **Data ("what we remember")** has switches for daily rides, Home & Work, chats (30 days), trips looked up, and exact location (off by default). There is also a "Delete everything" button. All of it stays on the phone, in `localStorage`. When a switch is on, the agent receives one summary line, such as "Usually takes the A from 59 St to 14 St around 8:40 AM on weekdays", and never the full history.
5. **The right side is a quick bar.** It holds Change view (Top, Aerial, Closer, Street), a compass that appears only when the map is rotated, and Center on my location.
6. **Notices you can tap.** A commute alert or line notice opens to show which station, which lines it affects and how, and since when. "Take the C instead" shows where to board and whether you need a transfer.
7. **Task screens match their frames.** That covers trip preview (it starts only when you press Play), Find exit, walking with landmark checkpoints, and following a train or bus (the M23 now runs crosstown). Buttons that went nowhere now ask the agent or are hidden.
8. **The agent's standing rules.** It suggests no businesses unless asked, gives no time advice, uses the memory summary only for the question asked, and opens 311 and crash data only on request. These rules have tests in `server/features/agent/prompt.test.ts`.
9. **Docs.** `docs/DESIGN_RULES.md` (the owner's design rules) and `docs/PDD.md` (the build plan) are new. The agreed frames are in `docs/design/frames/`, and `PROJECT.md` is updated.
