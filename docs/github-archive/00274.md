## Rules for whoever continues
- Process: issue → PR (conventional title) → green CI → squash-merge. Never force-push.
- Deploys: merging to main auto-deploys to gravebuster once CI on main passes.
- Bundle budget: all-JS 945 kB (currently ~861 kB after #260).
- three.js only behind src/lib/map/three*; no deck.gl.
- UI: Kresilo style, labelled buttons, drawers, no tooltips, no blocking popups.
- Privacy: mic/location/camera only on tap, never stored.
- Hosting: no Vercel. Files go through Octo to Cloudflare R2.
- gravebuster recreate: always set `CD_HOST_ENV_FILE=/srv/nyc-map-agent/.env` and `NYC_MAP_IMAGE=<current tag>`. A bare recreate caused a 502.
