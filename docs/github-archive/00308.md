On Top view the underground line breaks between the elevated stretches. Some of that stretch looks solid, and some of it looks like a torn dash.

The route shapes keep a separate copy for every branch. Where those branches share a trunk, the map paints the trunk once per branch. An elevated line is already solid, so the extra copies still look like one line. The underground line is a faint dash, so the copies pile up. Where the dashes line up they look solid. Where they slip they look broken.

Each color and grade is drawn once. A later shape keeps only the part that leaves the line already drawn, so a branch that splits off is kept and the shared trunk is not painted again. The Fulton Street tunnel through Euclid Avenue stays underground. The Liberty Avenue line east of Grant Avenue stays elevated. Planned-work dashes are unchanged.

To verify: open Top view over East New York, with X-ray off. The A between the elevated sections is one even dash, and the el on Liberty Avenue is still one solid line. The branch toward the Rockaway peninsula still leaves the trunk.
