# Issue #188: Navigation arrows for walking directions (street view and 2D Navigate)

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/188

**Problem.** Walking directions only draw a thin line. In street view (eye level) there is no sign of which way to walk, where the next turn is, or how far it is, so following a route at street level is guesswork. Alex asked for Google-Maps-style navigation arrows.

**What is wanted.**
1. In street view with directions active: the route drawn on the ground as a glowing ribbon with chevrons pointing the walking direction, a big turn arrow at the next maneuver, and a compact card ("Turn left on W 42 St, 80 m", miles to go) that advances as the camera moves.
2. A 2D "Navigate" mode: heading-up, tilted camera that follows your location, a chevron puck with an accuracy halo, a "Recenter" button, and an honest "Location accuracy: about N m" line. Location is asked for only when the button is tapped.
3. Styling follows the GTA 6 minimap / Google night navigation references: accent-coloured glow plus crisp core, walked part dimmed, colours from theme CSS variables.

This is phase 1 of 3 of Live View (phase 2: Compare mode with Mapillary / camera; phase 3: AR walking arrows on phones).

Refs: walking router is the existing FOSSGIS OSRM foot profile (`src/lib/api/routing.ts`).
