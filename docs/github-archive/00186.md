# Issue #186: Station names: bold, readable labels with route bullets

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/186

## Problem
Station names are barely readable when zoomed in: the only names on the map are the basemap's faint gray transit labels, which also lose label collisions to street names and place icons.

## Symptoms
1. **Faint names**: at Atlantic Av–Barclays Ctr around zoom 16 the station has no readable name next to its dot.
2. **Lost labels**: live train bullets and street names crowd out the basemap's station label.

## Ask
- A "Station names" switch under Transit in the Layers & filters drawer, on by default.
- When on: our own labels in bold ink with a halo that suits the theme (Ivory, Ink, MTA muted, Neon, and Auto once it lands), beside the station dot, with the route bullets, drawn above street and place names so they win.
- Hide the basemap's duplicate station labels while ours are on.
- Major stations from zoom 14, all stations from zoom 15.

Builds on #178 (route bullets in `src/features/transit/bullets.ts`) and #173 (the drawer).


---

**Pukujan commented, 2026-10-25**

Done in #434. Our station labels now appear from zoom 14 for stations served by four or more lines, so the big hubs are named first. One limit: the basemap's own station names can't be hidden on their own. OpenFreeMap tags subway, PATH and LIRR stations all as `rail`, so hiding them would hide the PATH and LIRR names too. A separate "Station names" switch would add a control the design rules ask us to avoid, so there isn't one.
