# Issue #161: My location: ask only on tap, use exact coordinates for directions, never keep them

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/161

Directions are less useful when the assistant has to guess where the person is starting from, but location is sensitive and should never be collected quietly.

What should change: a My location button that asks the browser for permission only when tapped; the exact coordinates go with the Ask/directions request for that request only; the server never stores or logs them (no database, no Octo, no R2 object storage, no request logs); a visible 'Stop sharing location' button ends sharing and forgets the position.

Done when a test proves the server path does not log or persist coordinates and the button flow works in screenshots.
