# Issue #175: CI: run all workflows on the self-hosted gravebuster runner

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/175

## Problem
Every GitHub Actions job in this repo fails within about 2 seconds because the account's hosted-runner (GitHub's own machines) Actions budget is used up, so no pull request can get a green check.

## Symptoms
1. **Hosted jobs die at start** — ci, secret-scan and stack-train all fail in 3–4 s with no steps run (e.g. the runs on `feat/cd-gravebuster`, PR #174).

## Plan
Move every workflow job to a self-hosted runner on gravebuster with labels `self-hosted, linux, x64, gravebuster`. The host has no Node or pnpm, so each job runs inside a container image (Node 22, Playwright 1.56.1 for e2e, Python 3.12 for Python jobs).

The shared `check-adopter.yml` workflow in Pukujan/agent-stack-train hard-codes `runs-on: ubuntu-latest` with no override, so this repo runs the same check inline until that workflow takes a runner input.
