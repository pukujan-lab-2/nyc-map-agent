# Issue #607: The stack upgrade moved CURRENT.md's 'In flight' and 'Next' sections into the history file

- State: closed (2026-10-31)
- Opened by Pukujan on 2026-10-31
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/607
- Labels: status:resolved

The stack upgrade to 1.0.3 ([#606](https://github.com/Pukujan-lab/nyc-map-agent/pull/606)) shortened `checkpoints/CURRENT.md` to its new cap, but it also moved the sections that say what is in flight and what comes next. A new session reading CURRENT now sees only the current projection.

## Symptoms

1. **Present-tense sections missing.** CURRENT is 13 lines with only "Current projection". "In flight", "Next" and "Keeping this file current" are in `checkpoints/history/2026-10.md` under "Archived from CURRENT.md on 2026-10-31". `AGENTS.md` still tells every pull request to update "Completed recently", "In flight" and "Next".

## Cause (confirmed)

The stack's archive step kept only headings in PCM's own vocabulary ("Active", "Next atomic action"), so it did not recognize this repository's "In flight" and "Next". This is being fixed upstream in [Pukujan/agent-stack-train#61](https://github.com/Pukujan/agent-stack-train/issues/61). Nothing was lost: the text is intact in the history file.

## Proposal

*(proposal)* Put "In flight", "Next" and "Keeping this file current" back into CURRENT as they were. Add a short "Completed recently" section that points to the history file for everything up to 2026-10-31. CURRENT stays under the 60-line cap.
