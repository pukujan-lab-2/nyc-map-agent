After hands-free voice started a trip preview, the listening orb stayed open on top of it. The mic kept listening while the trip played, so the screen looked stuck.

## What changes

Hands-free turns itself off when a trip preview or a followed route starts. Only the start counts: you can still turn hands-free on during one, and street-level Ask keeps it (its browser test covers that). Any spoken answer still finishes; only the mic closes. The change is in `src/features/agent/AgentOverlay.tsx`.
