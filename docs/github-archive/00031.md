# Issue #31: Octo mode: zero browser calls to NYC Open Data (boundaries + street panel via /api)

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/31

When VITE_DATA_BACKEND=octo the browser still fetches NTA 2020 / community district geojson (src/lib/api/nta.ts, districts.ts via socrataRequest) and street-panel 311/crash lists from data.cityofnewyork.us, which blocks first paint on mobile (~25 s). Plan: store simplified (mapshaper) boundaries for NTA 2020, community districts and boroughs in Octo (core.area_shapes; core.areas today is only a view of block counts), serve via GET /api/areas?level=… as compact GeoJSON/TopoJSON with long Cache-Control; serve street-panel detail lists from core.events via /api; keep Socrata only as the explicit fallback backend. Verify network log shows no data.cityofnewyork.us requests in octo mode; measure first render before/after on a throttled iPhone profile; profile the Pixel 7 drawer-open jank (~1.5 s).
