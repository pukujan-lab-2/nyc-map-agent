The default screen has too many controls: a left dashboard, a right rail of buttons and a row of chips. Alex chose Layout A from the mockups (mock2.html).

What should change: the default screen shows only a 'Where to?' search with Ask, one labelled 'Layers & filters' button and a small 'Transit on' pill. Everything else lives in one drawer (bottom sheet on phone, floating left card on desktop) headed 'Exploring <Neighborhood>' with sections: Getting around (Directions as the main button, Live trains, Live buses, Street view), Nearby stations with live arrivals, Layers, Places (hidden until chosen), Transit lines, Map detail (with a theme picker: Ivory, Ink, MTA muted) and Advanced. Near-monochrome tokens as CSS variables, one accent, subway lines muted until selected or focused. No tooltips, no icon-only controls.
