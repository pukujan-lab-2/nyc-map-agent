The idle map never rests: the baseline (#362) shows it redrawing 27 to 46 times a second with live trains on, and in dev `TransitLayer` re-rendered on nearly every React update with "Maximum update depth exceeded" warnings. 3D train models also caused repeated glitches (#319).

## What changes
- **#365 (`1f0f7e6`)**: the draw loop writes vehicle positions straight to the map source and the 3D layer and moves the Follow camera itself; React re-renders only when what the follow card shows changes. Fixes two render loops behind the depth warnings (the Live trains chip handler, and an inline handler in `place-toilets/ShopsToggle.tsx`). `addIcon` waits a tick and caches the SVG, which removes the `flushSync` warning.
- **#366 (`97cc653`)**: subway, LIRR and Metro-North always draw as a box in the route colour, with the route bullet above it in tilted views (above the viaduct when elevated). Only the bus model still loads. Top view is unchanged.

## How to verify
Dev build, about 350 live vehicles: `TransitLayer` re-renders went from about 74 a second to about 0.05 idle; no depth or `flushSync` warnings after load; the only model requested was `/api/vehicle-models/bus`; tapping a train opened its card and chase camera. Typecheck, eslint on touched files, and 141 transit and map tests pass.
