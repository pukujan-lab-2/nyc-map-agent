# Issue #233: feat(restrooms): shops & cafés with customer toilets (OSM) behind an 'Include shops & cafés' toggle

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/233

Problem: the Restrooms layer shows only NYC public restrooms, so in much of the city the nearest toilet a person can actually use (a café, fast-food place or shop that lets people use its toilet) is invisible.

What changes (proposal):
- Nightly ingest of OpenStreetMap places with toilets=yes (amenity=restaurant|cafe|fast_food|bar|pub and shop=*) via Overpass into a new table `core.place_toilets` (migration).
- Typed `/api/v1/place-toilets` route in openapi.json.
- In Layers & filters, while Restrooms is on, a labelled chip 'Include shops & cafés' (off by default). Calm marker, zoom 15+, badge 'Anyone' / 'Customers only', wheelchair mark where tagged; sheet with name, access, source link, Directions.
- Public restrooms stay primary. Refuge Restrooms is not ingested: its API publishes no data licence (the AGPL-3.0 covers the code only).

Done when: CI is green, the toggle is off by default, and the JS budget (945 kB) holds.
