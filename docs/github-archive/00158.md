# Issue #158: Simple controls: labelled buttons and layer chips instead of an icon rail

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/158

A first-time visitor sees a column of unlabelled icons and has to guess what each one does, so the most common tasks (getting directions, seeing trains) take trial and error.

What should change: a right rail of text buttons (Directions, Street view, Ask, More); Transit, Restrooms and Weather chips with a More layers menu; noise and crash layers only under Advanced; transit on by default; the home panel opens with 'Where to?' and the nearest stations.

Done when the app shows these controls at 1440 and 390 wide and old saved view links still open.
