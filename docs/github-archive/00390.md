The city's public restroom list was last updated June 2025, so closures and new restrooms are missing, which weakens a primary use (finding a restroom nearby).

## What changes
- A nightly OpenStreetMap ingest (`server/features/restrooms/osm.ts`), same pattern as the shop and café toilets: one Overpass query, refuses an empty result, nightly replace into `core.osm_toilets` (migration `20261024000100_osm_toilets.sql` with up and down; it also adds `updated_at` to the `core.restrooms` view).
- `/api/restrooms` merges both sources (`merge.ts`, pure): an OSM toilet within 40 m of a city restroom is the same place; city fields win, OSM fills gaps. Each record carries its source and `asOf`. If the OSM table can't be read, the city list is served alone.
- The card shows "OpenStreetMap, updated …" or the city source with "some details from OpenStreetMap", plus Fee, Changing table and Unisex rows. Nearest-restroom logic runs on the merged set.

## How to verify
