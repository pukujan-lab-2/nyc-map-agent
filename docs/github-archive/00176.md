## Problem
Every Actions job fails within about 2 seconds because the account's budget for GitHub-hosted runners is used up, so nothing can pass CI. Refs #175

## What changes
Every job now has `runs-on: [self-hosted, linux, x64, gravebuster]`. **The runner must be registered with exactly these labels: `self-hosted`, `linux`, `x64`, `gravebuster`.** This PR stays red/queued until that runner is online, so do not merge it before then.

| Workflow | Job(s) | Before | After |
|---|---|---|---|
| ci | check, size, deps, lint, api | ubuntu-latest | gravebuster, container `node:22-bookworm` |
| ci | e2e | ubuntu-latest + `playwright install --with-deps` | gravebuster, container `mcr.microsoft.com/playwright:v1.56.1-noble` (matches `@playwright/test` 1.56.1; browser install and cache step removed) |
| feed-health | ping | ubuntu-latest | gravebuster, node container |
| nightly-ingest | ingest | ubuntu-latest | gravebuster, node container; `sources` input now passed through an env var instead of pasted into the script |
| Issue Triage | triage | ubuntu-latest, no timeout | gravebuster, `python:3.12-slim`, 10 min timeout |
| secret-scan | gitleaks | ubuntu-latest | gravebuster, node container |
| stack-train | check-adopter | reusable `Pukujan/agent-stack-train/.../check-adopter.yml@main` (hard-codes ubuntu-latest, cannot be overridden) | same check run inline in `python:3.12-slim` |

Also on every job:
- Actions pinned by commit SHA (checkout, setup-node, pnpm/action-setup, gitleaks-action).
- `timeout-minutes` set; `concurrency` groups per PR/ref (PR runs cancel superseded runs; main pushes and ingest never cancel).
- Top-level `permissions: contents: read` (secret-scan adds `pull-requests: read`, triage keeps `issues: write`).
- A final `if: always()` step empties the workspace, and the pnpm store lives inside the throwaway container, so nothing carries over between runs on the persistent host. The pnpm cache goes to GitHub's cache service, not the host disk.
- `.github/actionlint.yaml` declares the `gravebuster` label so actionlint passes.

## What stays the same
Triggers are unchanged: still `pull_request` (never `pull_request_target`), push to main, schedules. Step commands and secrets are unchanged; no secret is echoed.

## Host setup gravebuster needs
- The runner service user in the `docker` group (`sudo usermod -aG docker <runner-user>`, then restart the runner service), since every job uses `container:`.
- Outbound access to ghcr/docker.io/mcr.microsoft.com for the images, and github.com.
- Nothing else: no Node, pnpm or Python on the host.

## How to verify
1. `gh api repos/Pukujan/nyc-map-agent/actions/runners` shows the gravebuster runner `online` with the four labels.
2. Re-run this PR's checks; all jobs pick up on gravebuster.
