# Issue #282: A question in the top search bar never reaches Ask the map

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/282

A question typed in the top search bar never shows up in Ask the map, and on a desktop window the bar is too narrow to read the question.

## What happens

1. **The question stays in the search box.** Typing "how do i get from my place to rockaway" and pressing Ask opens Ask the map on the example prompts and an empty "Where to?" field.
2. **The desktop bar clips the question.** The bar is fixed at 360px, so the end of the question is cut off.

## Why

The Ask button only opens the panel. It does not hand the typed text over. The trip assistant replaced the older chat panel, and it never reads the question that panel used to pick up. An empty Ask should still just open the panel. Enter on a highlighted neighborhood, address, or station should still go there.

## Change

Ask sends the typed question into Ask the map and clears the search box. On a desktop window the search bar grows with the window, up to 720px, so a full question stays visible. The details sheet stays 360px. The phone bar already spans the screen.
