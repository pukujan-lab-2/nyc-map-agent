On every visit the map waited for the network before it could draw subway lines and stations, even though they had not changed since the last visit. On a slow phone network that is the blank stretch people see first.

**What changes**
- `src/lib/queryKeep.ts` saves a short list of slow-changing queries in the browser's IndexedDB after they load: line shapes and stations, the bus line list, the X-ray station data and district outlines.
- At the next start it puts them back if they are under 3 days old, never over data that has already arrived. It marks them stale, so React Query fetches fresh data in the background and replaces them.
- Live train positions, alerts and anything tied to one place are never kept, because old trains drawn as if live would mislead.
- `main.tsx` turns it on. Where IndexedDB is missing or blocked, nothing happens.

**How to verify:** `npx vitest run src/lib/queryKeep.test.ts` covers what is kept, the round trip with its age and stale mark, no overwrite of newer data, and the age cut-off. On the live site, load the map, reload with the network throttled to "Slow 3G", and the lines appear before the requests finish.

**What stays the same:** all fetching and refresh intervals. The main bundle is 498 kB of its 535 kB limit.
