# Issue #373: Help still works underground with no signal

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-24
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/373

Stations usually have no signal. When it is lost, maps cannot help choose the exit, and on surfacing they do not know which way the user faces. Helping underground needs the data on the phone before the signal goes.

## What is needed
- When a trip involves the subway, the app keeps the station layout, exits and the route on the device before entering.
- It asks whether the user is underground instead of assuming the street.
- With no network it still shows the exits for the station and the route to the destination.
- On surfacing it helps recalibrate facing (see Live View, PR #359).

## Acceptance criteria
- [ ] With the network turned off inside a station, the exits and route still show.
- [ ] The app offers an "I'm underground" state.
