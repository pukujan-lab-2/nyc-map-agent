## What changes

- **Pins.** `stack-manifest.json` pins `agent-stack-train` alone and follows the train, which certifies 1.0.1 at `2e32f2c`. `.coord/assignment.json` and `.coord/hotload.lock.json` move their pins to that commit.
- **Seats are unchanged.** The `grokbot-skyline@box` seat, the check-in issue #156 and the boss history stay exactly as they were. Only the pins and the generated notes change.
- **Issues close on merge.** OIO 0.3.0 adds `oio-close-on-merge.yml`. When a pull request merges, it closes the issues named with `Closes`, `Fixes` or `Resolves`. `Refs #N` never closes anything. `oio-close-sweep.yml` runs daily, but only reports until the repository variable `OIO_CLOSE_SWEEP_APPLY` is set to `true`.
- **The triage workflow goes back to OIO's file.** `issue-triage.yml` was edited by hand: `cancel-in-progress`, a 10-minute timeout, a Python container, a pinned checkout and a workspace cleanup step. OIO refuses to upgrade over an edited managed file, so this restores its own version. The cleanup step was for the self-hosted runner, which this workflow no longer uses since #599.
- **Boot paths.** `AGENTS.md` and `scripts/agent-hygiene.sh` point at `~/.cache/acs/deps/agent-stack-train` (folders `acs/`, `pcm/`, `cgm/`, `oio/`) instead of the four old checkouts. That checkout exists on the Mac at `v1.0.1`.
