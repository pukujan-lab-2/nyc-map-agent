The home screen asked the server for 311 block counts that only the analytics views draw, which added one request and its wait to every first load.

Refs #368

## What changes

`src/pages/Index.tsx` asks for those counts only while a noise, crash, combined or data-layer view is on. Otherwise it passes an empty source list, so no request goes out.

## How to verify

Open the home screen and watch the network panel: no `/api/blocks` request until you turn on an analytics view, then one.

## What stays the same

The analytics views load their counts exactly as before. An earlier version of this PR also shared the transit alerts feed with the home screen; that needs one feature to import another, which the module-boundary rule does not allow, so it is left out. The alerts request still runs only for people with a saved commute.
