**Problem.** Exit help pointed at an exit without checking where you are: no prompt to share your location, no "you're not at this station", and no way from you to the exit. It also opened on top of the station and line panels. Separately, after a deploy, tapping My day in a tab opened earlier blanked the whole page.

**Why the page went blank.** My day's code loads as its own file. A deploy renames those files; the server then answered the old name with the app's HTML page (status 200), the browser could not run it as a script, and with no error boundary React removed everything. Checked live: the previous build's main script now returns `text/html`.

## What changes

1. **Exit help checks you are at the station first.**
   - Location not shared: "Are you at Flushing Av?" with **Share location** and **I'm here**. Nothing asks the browser until you tap.
   - Shared and more than 250 m away: "You're about 7.4 km from Flushing Av." with **Walk there** (asks the agent), **I'm here**, and **Use <station>, by you** when one is close.
   - At the station: a green dotted line from you to the exit, "About 175 m from you", and the map framed on both. **I'm out** shows only once you are there.
   - Your "I'm here" wins over a stale fix underground.
2. **One panel at a time.** Opening exit help closes the place and line panels. Tapping a station or line afterwards closes exit help.
3. **Stale builds reload instead of blanking.**
   - Missing `/assets/*` files return 404, not the HTML page.
   - The app reloads once when a code file is gone (at most once a minute).
   - Error boundaries wrap the app, each feature overlay and My day. One failing part shows a short message, not a blank page.
