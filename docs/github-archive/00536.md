**Problem.** At DeKalb Av the owner couldn't pick a line. The B D N Q R W bullets under a station are drawn as one image, so the map only knew "the station" was tapped, and a train parked there took the tap first (opening the R, or a chooser with the wrong lines).

**What changes.**
- A tap on the bullet row works out which bullet it hit from the row's layout (`rowBulletAt`, pure and tested), then opens that station with only that line shown — the same as tapping the line in the station card.
- This runs before the train/station tap cycle, so a parked train no longer steals it. Taps on the name or the station dot behave as before.

**How to verify.** Live at DeKalb Av, zoomed in: tap N, then Q; each opens the station narrowed to that line.

**Unchanged.** Tapping a train, the station dot, tracks, or bullets in 3D when the station is raised.
