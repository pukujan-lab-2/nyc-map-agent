Issue #11 asks for self-hosted 3D buildings as static 3D Tiles; nothing existed beyond a plan line.

## What changes
`pnpm build:3dtiles <borough>` fetches Building Footprints (`5zhs-2jue`) from NYC Open Data, extrudes each footprint to its roof height, groups buildings into 1 km tiles, and writes `tile_*.glb` files and a `tileset.json` (3D Tiles 1.1) to `public/tiles/3d/<borough>/` (gitignored). No external tools are needed. A doc, `docs/3D-TILES.md`, explains running and hosting. No app runtime code changes.

## How to verify
8 unit tests cover the geometry (heights, projection, ring cleaning, triangulation, glTF container, tileset); typecheck and lint of the new files pass.

## Not checked
The Socrata fetch and a real borough build were never run, no tileset has been validated or loaded in a viewer, so the glTF axis handling is unconfirmed. Limits: heights start at z = 0, courtyard holes are ignored, no levels of detail, one grey material.
