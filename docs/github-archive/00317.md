# Issue #317: Hide bus-stop icons

- State: closed (2026-10-23)
- Opened by Pukujan on 2026-10-23
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/317

From neighborhood zoom, the basemap draws a bus-stop icon on every stop, and street level adds a blue pole for each one nearby. That covers the map.

Add a Bus stops switch in the Layers list and a Hide bus stops pill in Map detail. Off hides those icons, their names, and the street-level poles, and skips the nearby-stops request. On keeps the current zoom gate: icons from zoom 15, names from zoom 17. The choice is remembered with the other map options.

Live bus vehicles, a selected route's stops, subway stations, and restroom kiosks stay.
