Asking for a trip started the fly-through immediately, and choosing another option kept animating the old route. The owner also wants "tomorrow at 9 am, from here to here".

## What changes
- Cause: the prompt told the model to start the preview with every trip answer, and the client started it as soon as the command arrived; picking another option never told the player.
- The trip shows with a Play button and speeds (2x, 5x, 10x, 30x); nothing plays until Play. Choosing another option stops the animation and restarts on the new route from its start (chat card or trip panel). Speed changes continue from the same spot (kept from #289; a one-line change to restart instead).
- "tomorrow 9am" is resolved server-side in New York time. Answers for a future trip state planned work and skipped stops covering that time, the forecast for that hour, and that live delays aren't known yet. A time beyond the 7-day forecast now shows no weather instead of the wrong hour.

## How to verify
