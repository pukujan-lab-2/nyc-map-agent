The product's main goal is an accessible chat and voice agent over the map, but the screen led with a top search bar and a small "Ask" button.

## What changes (behind the new flag `agentHome`, off by default for review)
- A bottom chat bar over the map (text, voice, send; 44 px targets; safe-area aware) on the existing agent stream.
- A Siri-style voice mode with a live waveform from the microphone level; a clear message and text fallback when speech recognition isn't available.
- An "Agents working" panel listing each tool step instead of a spinner (new `step` line in the stream; older clients ignore it), and a spoken status after 2.5 s for voice questions, localised for en, es, zh, ru, bn, ht, fr, ko.
- Answers in a compact sheet above the bar with #383's map buttons, now 44 px tall.
- The browser language is sent with each question; replies follow the user's message language.
- The bar publishes `--chat-bar-h`; `ViewSwitcher.tsx` and `MapCompass.tsx` add it to their bottom offset so they stay clear of the bar.

## How to verify
Agent and flag tests (104) pass; typecheck, eslint on touched files and depcruise pass. In the browser with a fake agent stream: at 390×800 the bar, steps panel and answer with buttons appeared; with a fake microphone the waveform animated and a Spanish status was spoken.

## Not checked
