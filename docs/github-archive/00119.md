Closes #45

Root cause: in Octo mode the registry path asked /api for noise and crashes by grid cell (r:c keys) with the map's 90-day window. Crashes only have a 12-month rollup, so the 90-day query came back empty, and grid keys don't match the real tax-block tiles' feature ids (boro*100000+block), so no block got a shade. Now noise and crashes always come from the aggregates the map already loads: BBL-keyed, and crashes on their 12-month window. Headless at Bushwick z13 (advanced mode): src:crashes, avg(noise+crashes) and src:noise all shade blocks (screenshots fix4-layers-after-*.png).

Known limit: other registry sources (All 311 etc.) still return grid cells from /api, so at the Blocks scale on tax-block tiles they shade nothing; the neighborhood scale works. They need a BBL-keyed endpoint; follow-up. The noise category filter no longer narrows the noise view in Octo mode, because the aggregate is unfiltered.
