Live buses only offered a page of 20 routes at a time (for example Q1–Q19), and the Live buses switch did nothing until a page was chosen. There was no way to pick single lines or limit how many buses draw per line.

## What changes
- **Pick any lines.** The Bus lines section in Layers & filters shows a search box, borough pills, and a tap-to-toggle list of routes. Up to 20 lines. Picked lines show as removable chips with Clear all.
- **Buses per line.** A stepper sets 1–10 (default 3). Each line shows its nearest buses to the map centre, picked on each refresh. A followed bus is never dropped.
- **URL state.** `?busLines=Q1,B41&busCap=2`. An old `?busPage=` link still opens that page's lines until the first edit. Turning Live buses off clears the picked lines.
- Trips and replacement shuttles still win over picked lines, as before. The server API is unchanged (it already limits a request to 20 routes).

## How to verify
- Open Layers & filters, find Bus lines, pick B41 and Q2, set 2 buses per line: at most 2 buses per line draw, and the URL updates.
- Search "b4" narrows the list; Clear all returns to "Buses stay off until you pick a line."
- Checked in a browser against the live bus API (read-only proxy). Typecheck, lint, and the 87 transit unit tests pass. The e2e suite was not run, and the on-map bus count was not counted by eye.

## Unchanged
- Trains, trip and shuttle bus reveal, the bus feed and estimation, and the server.
- A separate full dashboard is not part of this PR; the picker is a section of the existing drawer.
