# Issue #290: Restrooms barely show in street view, and street view is very slow

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/290

Street view hides the WC icons, and the restroom source only keeps the five closest public restrooms in the city. The 3D kiosks can only draw what is in that source, so on a block you get the wrong bathrooms, or none, and the five get rewritten every time the camera settles.

Walking and looking call jumpTo on every frame. In MapLibre 5.24 that fires moveend each time. Street-name signs, storefronts, and hydrants rescan every loaded tile on that event, which is what makes street view stall.

At neighbourhood zoom the map should still show only the closest few. At street zoom it should keep the restrooms within a few blocks. A look that only turns your head should not rescan the streets.
