# Issue #234: Ask box returns 400 for every question

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/234

Typing 'how to get to time square' into Ask shows 'The assistant returned 400.'

Repro: `curl -X POST https://nyc.design-bakery.com/api/v1/agent -H 'content-type: application/json' -d '{"messages":[{"role":"user","content":"hi"}]}'` returns `{"error":"bad_request"}` 400, on /api/agent and /api/v1/agent alike.

Cause: AGENT_ROUTE declares a JSON body, so the @​hono/zod-openapi validator reads c.req.raw before the handler runs. The handler then calls request.json() on the consumed stream, gets null, and zod rejects it. The UI also shows the raw status code.
