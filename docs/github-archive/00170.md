# Issue #170: Readable transit map on phones: pale streets, no place icons by default

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/170

On a phone the subway and bus lines are hard to pick out: yellow and orange streets with dark casings, every minor street name and hundreds of shop and church icons compete with them. Investigation also found that one tile or data error while the map style is still loading swaps the whole map to a raster fallback that no style rule can restyle.

What should change: on phones (and whenever Transit Focus is on) streets are plain and very pale with no casings, minor names, one-way arrows or shields; major street names stay faint but legible. Place icons are hidden by default with a labelled Places chip to bring them back, saved across visits. The raster fallback happens only when the style itself fails.

Done when screenshots at 390 and 1440 wide show the difference and the choice survives a reload.
