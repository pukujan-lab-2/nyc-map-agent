Tapping Baño with the app in Spanish gave this answer on the live site: "No sé desde dónde me escribes, así que toca Use my location debajo de mi respuesta o escribe una dirección de partida.No sé desde dónde buscas: toca Use my location…". The same reply appears twice, glued together with no space, and it calls the button by its English name, while the button itself reads "Usar mi ubicación". This happens because the model wrote a reply, called a tool, then wrote the reply again, and the app joined everything it streamed into one string.

## What changes

- **One answer, not two** (`src/features/agent/answerText.ts`, `AgentOverlay.tsx`). The app now keeps each piece of text the model writes between tool calls. If a piece is restated by the next one (they start with the same three words, or the same first characters in Chinese and Korean), the earlier piece is dropped. The pieces that remain are set apart as paragraphs instead of running together. The spoken answer uses the same text.
- **The button's own name** (`answerText.ts`, `server/features/agent/prompt.ts`). When the reply carries the Use my location button, "Use my location" in the text becomes the name the button shows in the app's language. Remind me already worked this way. The prompt now also lists the button's name in all eight languages, the same way it does for Remind me.

## How to check

1. With the app in Spanish and location blocked, tap Baño. The answer appears once, and the text says "Usar mi ubicación", like the button.
2. Ask a line question that runs a tool, such as "how is the 4 train". Any text the model writes before and after the tool shows as separate paragraphs.

`answerText.test.ts` covers a restated piece (Spanish and Chinese), different pieces kept as paragraphs, and the button-name swap.

## What stays the same

The tools and the answer buttons are unchanged, and the prompt only gains the button names. A reply that the model writes once looks exactly as before. `checkpoints/CURRENT.md` now lists this phone round (#471 to #478) and what is still English only.
