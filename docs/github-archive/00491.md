**Problem.** A "which exit for the Empire State Building?" answer only gave a "Show the exit" button that flew the map to one point. You had to read the text to learn the corner and the walk, and on a phone that text covers the map.

**What changes.**
- Main's `station_exit` tool (from #422) now sends a new `showExit` map action instead of a plain fly-to. The tool itself is unchanged: it still handles "here" underground, the walk's turns, a trip you can start, and is wrapped in `sourced()`.
- The client draws the answer at once, north up: the exit with its corner label, the dashed walk to the place, and your dot when you're within 1.5 km. Everything is framed above the small answer card.
- On an exit answer, the card shows a compass hint. "Show my direction" turns on a heading arrow on your dot (iOS asks on that tap); "Calibrate: move your phone in a figure 8" shows when the compass is off.
- `exitLayer` loads on the first exit answer, so most of the new code stays out of the overlay chunk.

**How this branch was reconciled with main.** It was started before #422, which had added its own `station_exit`. Main's tool and prompt lines win. The branch's duplicate tool, `server/features/agent/exit.ts` and its prompt line are gone. What's kept is the map drawing, the compass and the new action kind.
