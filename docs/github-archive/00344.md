# Issue #344: Migrate zod 3 to 4 to clear a high advisory

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-23
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/344

`pnpm audit --audit-level high` started failing on every pull request on 2026-10-23 because of a new advisory, [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5): zod can exhaust memory while validating oversized input. It affects every zod below 4.6.6. The repo uses zod 3.25.76 (a direct dependency and the one `@hono/zod-openapi` 0.19 needs), and there is no 3.x patch.

## What is needed
- Move `zod` to 4.6.6 or later. `@hono/zod-openapi` 0.19.x and `@asteasolutions/zod-to-openapi` 7.x are built for zod 3, so they need matching upgrades, and the OpenAPI output (`openapi.json`, `pnpm openapi:check`) has to be regenerated and checked.
- Remove `GHSA-mrhx-c7xc-m3w5` from `auditConfig.ignoreGhsas` in `pnpm-workspace.yaml` when done.

## Why this is baselined for now
The only place zod validates untrusted input is the API's request bodies (small JSON). The memory-exhaustion case needs an oversized payload, and the server already sits behind the edge router. This is a stopgap, not a fix.

Refs: pull requests that were blocked by this check include #342 and #343.
