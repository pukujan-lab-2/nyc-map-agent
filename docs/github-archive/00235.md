# PR #235: fix(agent): stop every Ask request from returning 400

Closes #234.

The agent route declares a JSON body, so the zod-openapi validator reads `c.req.raw` before the handler runs. `agent.POST` then called `request.json()` on a consumed stream, got null, and returned `bad_request`. That broke both `/api/agent` and `/api/v1/agent`. The handler now gets a fresh Request built from Hono's cached JSON.

- `server/features/agent/contract.test.ts` sends the client's `askAgent` request through the mounted app on both paths, and checks that a bad body is still a 400.
- A failed request now shows plain words in the UI instead of 'The assistant returned 400.'
