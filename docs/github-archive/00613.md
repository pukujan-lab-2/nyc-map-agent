## Change and scope

1. `deploy/vps/autodeploy.sh` copies Octo's deploy pattern. It fetches `origin/main` and builds `nyc-map-agent:<12-character commit>`. It swaps `nyc-map-web` to that image and waits up to 150 seconds for the health check. If the check fails, it puts the previous image back and fails the Komodo run, which sends an alert. A failed commit is recorded in `deploy/.deploy-failed` so it isn't rebuilt every 5 minutes. The tag goes into `deploy/.env`, which compose reads by itself, so Komodo's own `compose up` afterwards changes nothing. Komodo's agent runs as root, so git runs as the checkout's owner.
2. `deploy/docker-compose.vps.yml` adds `nyc-map-web` to the `study-os_edge` network. That lets Cloudflare tunnel A reach it as `nyc-map-web:8080`, the same way it reaches acs, octo and umami. Both networks fall inside the address range the LFM3 bridge accepts (172.20.0.0/16 and 172.28.0.0/16 in 172.16.0.0/12), so chat keeps working.
3. `deploy/README.md`, `docs/PDD.md` and `checkpoints/CURRENT.md` describe the Komodo deploy and the one step left for the public name.
