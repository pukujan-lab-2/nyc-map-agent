## Problem

On a slow phone, the map stays empty for about 9 seconds. Its two citywide tiles (395 kB) share the connection with the 220 kB subway file, the 70 kB neighbourhood shapes and the 70 kB live-train batch. MapLibre (the map library) also asks for its label fonts only after it has parsed the tiles, and it draws nothing of a tile until those fonts arrive. Separately, #469's stylesheet preloads didn't match Vite's `crossorigin` stylesheet links, so the browser downloaded both stylesheets twice.

## What changes

- **The map comes first.** A new `src/lib/map/basemapReady.ts` turns true when the basemap's tiles are in: on MapLibre's `load` event, or on the base source's data event in browsers that never send `load`. An 8-second fallback means the data still loads if the map never reports.
  - The subway file, live trains and alerts (`src/features/transit/hooks.ts`) wait for it.
  - So do Underground's copy of the subway file and the neighbourhood shapes (`src/lib/geo/aggregate.ts`).
  - Copies kept from a previous visit still show at once.
- **Fonts start early.** The two fonts the default style uses are requested as the map mounts (`warmBasemapFonts`), so they are cached before the tiles are parsed.
- **The style starts early.** `index.html` preconnects to the tile server and preloads the style and the tile index.
- **Stylesheet preloads carry `crossorigin`**, so each stylesheet downloads once.

## How to verify

Local build, phone-speed throttling (4× CPU, 1.6 Mbps, 150 ms delay), 2 runs each:

| | Before | After |
|---|---|---|
| Base map tiles and fonts ready | about 10.1 s | about 7.3 s |
| Subway file done (trains can draw) | about 12.8 s | about 8.3 s |
| Stylesheet downloads | 4 | 2 |

All 1278 unit tests and all 32 end-to-end tests pass, as do lint, knip (the dead-code check) and the size budgets. In the browser pane, the lines and moving trains draw as before.

## What stays the same

Trains and buses still always draw. They now start right after the base map, instead of competing with it. On a fast connection the base map is ready almost at once, so nothing visibly changes.
