**What**
- `core.area_shapes` (new table next to the `core.areas` view; Octo has no PostGIS so geometry is jsonb): NTA 2020 (262) + community districts (71), simplified with mapshaper 0.7.89 (MPL-2.0, dev dep) Visvalingam 8% keep-shapes. NTA payload 4.6 MB → 323 KB (71 KB gzip). Loaded by `pnpm load:areas`.
- `GET /api/areas?level=nta|cd`: same property names as the Socrata GeoJSON so the existing parsers are reused; `max-age=86400, s-maxage=604800`.
- `marts.aggregates` + `pnpm build:aggregates`: the browser worker's rollup (NTA + block detail, top types, addresses, crash streets/intersections — the street-panel lists) is now `src/lib/geo/aggregateCore.ts`, fed by Socrata pages in the worker or by Octo raw.noise_311 / raw.crashes pages in the script. (core.events has no address / cross-street columns, so the lists come from raw.*.) Noise 90d 204,538 rows, noise 12mo 783,566, crashes 12mo 51,455; 1.4–1.9 MB JSON each.
- `GET /api/aggregate?dataset=&window=` serves it (`max-age=600, s-maxage=3600`).
- Client: in octo mode boundaries, districts and rollups use these endpoints; Socrata remains the explicit fallback backend.
- Nightly ingest runs load:areas + build:aggregates after refresh.
- Drawer: removed the full-screen `backdrop-blur` on the sheet overlay (blur over a live WebGL canvas is a known mobile GPU cost).
