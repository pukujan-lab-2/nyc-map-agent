## Summary

Adds a continuous-deployment pipeline for the map app on `gravebuster`, served at `nyc.design-bakery.com`.

- **`deploy/cd/`** — deploy API and pipeline: exclusive lock, fetch, checkout, build, container swap, health poll, automatic swap-back on unhealthy, append-only JSONL run history. Session-cookie auth for the dashboard, bearer token for CI, SSE log streaming, rate-limited login.
- **`deploy/dashboard/`** — ABA-generated operator dashboard at `/deploy`: live card, deploy history, per-step run detail with streamed logs.
- **`deploy/`** — three-container stack (`web`, `cd`, `edge`), Caddy edge routing `/deploy/api/*` to the deploy service, `/deploy*` to the dashboard, everything else to the app.
- **`.github/workflows/ci.yml`** — a `deploy` job that runs only after every other job passes on `main`, triggers the deploy for the pushed sha, and polls to a terminal status.
