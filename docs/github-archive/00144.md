Closes #67

Why the signboards never showed:
1. The sign mesh refilled on `moveend` and `idle` but never asked for a repaint, so new signs didn't appear until the next camera move.
2. Weather and hazards animations repaint the map continuously, so it never goes `idle`. `moveend` fires before the tiles have loaded, so the sign list stayed empty (debug showed `count: 0` for 285 frames).
3. From the usual 3D view (z17–19) a real 0.8 m plate is only 2–4 px tall.

Fix (threeLayer.ts only):
- repaint after every refresh;
- refresh on `sourcedata` when `city3d` loads, and about once a second from `render` while drawing;
- real size at eye level; above that, plates grow up to 6x so they stay about 14 px tall; wall gap 0.05 m → 0.15 m.
