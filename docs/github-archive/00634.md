### Summary

The app's speech-to-text endpoint sends every voice recording to Groq's hosted Whisper by default (`server/features/agent/stt.ts`, added in #401 on 2026-10-24 so the mic works in Brave). The owner did not want Groq and asked for it to be removed. Nothing in `docs/PRIVACY.md` tells riders their audio goes to Groq.

### Identity and Lineage

Repository Pukujan-lab/nyc-map-agent. Code: `server/features/agent/stt.ts`, `stt.test.ts`, `.env.example`, `deploy/.env.example`, `docs/PLAN-copilot-port.md`. Introduced by PR #401 (author Pukujan, Claude Opus 5.5 co-author). The owner's own plan for a shared voice host on the MacBook Pro is in `docs/PLAN-copilot-port.md`.

### Acceptance Criteria

1. No `GROQ_API_KEY`, `api.groq.com` or Groq default remains in code, tests, env templates or docs the app ships (the owner's research notes are left alone).
2. `/api/stt` answers 503 `stt_unavailable` unless `STT_BASE_URL` is set, so no audio leaves the server for a service the owner did not name.
3. Any OpenAI-compatible Whisper server still works through `STT_BASE_URL`, `STT_API_KEY` (optional) and `STT_MODEL`.
4. `npx vitest run server/features/agent/stt.test.ts` passes.

### Boundaries and Next Action

In scope: removing the Groq default and wording. Out of scope: choosing or running a replacement (a Whisper server on the Pro is the owner's plan) and the front end. Next action: remove it, open the pull request, then tell the owner the mic stays off until `STT_BASE_URL` is set.

### Symptoms

1. **Hosted default nobody chose:** with only `GROQ_API_KEY` set, voice recordings go to api.groq.com.
2. **Mic off on the live site:** nyc.design-bakery.com shows "Voice isn't set up on this server yet" because no key is set on the VPS.
3. **Undisclosed:** `docs/PRIVACY.md` does not mention the recording being sent anywhere.

### Hypotheses (unverified)

H1. Making `STT_BASE_URL` mandatory leaves no path that reaches Groq. **Status:** unverified. **Would confirm:** a search for `groq` in shipped files finds nothing and the unset-URL test returns 503. **Would refute:** any code path still builds a groq URL. **Experiment:** `grep -ri groq` over code and templates, and the unit test.

### Counter-signal

Removing the default also turns the mic off for Brave and Firefox until another Whisper server is set, since the browser's own recognizer does not work there.

### Honest Caveat

This does not provide a replacement; voice stays unavailable on the live site until the owner runs one.

### Problems vs Gaps

Problem: audio would go to a hosted service by default. Gap: no replacement speech server, and the privacy page is silent on audio.
