On the live site, with the app in Spanish, tapping Baño gave an answer that opened in English: "I'll look that up for you." The model writes a line like that before it calls a tool. Since #478 that line shows as its own paragraph, so a Spanish reader still saw it in English. On a phone, the same answer also clipped its first word: the answer scrolls under the round close X, and that X had no background, so the screen showed "✕'ll look".

## What changes

- **No line before the tools** (`server/features/agent/prompt.ts`). A new prompt rule: write nothing before or between tool calls, call the tools first, then write one reply in the user's language. The app already shows that it is working.
- **A solid close X** (`src/features/agent/AgentHome.tsx`). The answer's close button gets the same solid dark fill, thin border and shadow as the task screens' close buttons from #472. Text that scrolls under it is hidden behind it instead of showing through.

## How to check

1. At 375×667, with the app in Spanish, ask "¿Cómo funciona la línea 4 ahora mismo?". The answer is all in Spanish, with no English opening line.
2. Let the answer fill the area so it scrolls. The X stays a solid dark circle, and no letters show through it.

## What stays the same

The close button's place, size and label are the same, and so are the tools and the answer buttons. The prompt only gains the one rule.
