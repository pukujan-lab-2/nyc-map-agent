# Issue #182: Subway entrance signs: station name and route bullets on the 3D kiosks

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/182

At street level, each 3D subway entrance has a blank dark sign (Alex's screenshot at Times Sq). Each sign should show the station name in white sans on a black band, with the station's route bullets below it in MTA colours, the way real NYC entrance signs do. Use the station complex's routes from MTA Subway Entrances and Exits (data.ny.gov i9wp-a4ja), shipped through Octo/R2. Draw one cached canvas texture per station in threeLayer.ts. Put a shared route-bullet helper in src/lib/transit/bullets.ts.
