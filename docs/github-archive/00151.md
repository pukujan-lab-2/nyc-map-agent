Closes #106 (the last open item: hero landmarks; the skyline pass itself was #131)

- `scripts/make-landmarks.mjs` builds four low-poly GLB models with three's GLTFExporter (CC0, authored here from published dimensions, 9–36 KB each): Empire State (setbacks, mast, antenna), Chrysler (terraced crown, needle), One WTC (podium, tapering shaft, spire) and the Statue of Liberty (Fort Wood, pedestal, statue).
- `src/lib/map/landmarks.ts`: one list shared by the tile build and the map. The build leaves those footprints out, so the model is the building.
- `createLandmarksLayer` in threeLayer.ts uses the shared renderer. Each GLB is fetched only when the camera is within ~3 km, and shows from z14.
- Fix: the hydrant and vehicle layers' `onRemove` disposed the shared three.js renderer, which would break every other three.js layer. They no longer do.
- Glue code only: GLTFLoader/Exporter from the pinned three.
