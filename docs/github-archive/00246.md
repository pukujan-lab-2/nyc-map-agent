## What and why

- DEFAULT_MODEL is now `cb/deepseek-v4.1-flash`. The old id has no provider prefix and InferHub rejects it; `ali/` returns 402.
- New optional `INFERHUB_MODEL_FALLBACKS` (comma-separated). On 402, a 4xx `model_not_found`, or any 5xx, the request is retried with the next model. It's a fetch wrapper around the provider, so streaming is unchanged. Logs show the HTTP status and provider error type only, never the key.
- Geocoding now checks a curated landmark list (Grand Central, Penn, Port Authority, Times Square, Union Square, Barclays, WTC/Oculus and a few more), then exact GTFS station names, then GeoSearch. GeoSearch now asks for 5 results, takes the highest confidence, and drops anything under 0.5. This fixes 'Grand Central' landing on 700 Esplanade Gardens Plaza.
- Tests: model-fallback.test.ts (mocked fetch) and places.test.ts.
