**Boundaries:** dependency-cruiser now allows `three` only in `src/lib/map/three/**` and `threeLayer.ts`, and a new rule `three-internals-behind-threeLayer` keeps everything else importing `threeLayer.ts`, not `three/**`. (The old rule also named a `streetSigns.ts` that no longer existed.) docs/MODULES.md updated.

**Mature-library swap:** hand-rolled `111_320 × cos(lat)` metre maths (hydrant/sign/storefront radius checks, storefront placement, landmark distance) → MapLibre `MercatorCoordinate` / `LngLat.distanceTo`. react-three-map (the report's scene-glue replacement) stays out of scope: report PR10, optional, behind a flag.

**Tests:** new `three/projection.test.ts` (5) and `three/picking.test.ts` (4); suite 172 passed / 8 skipped (was 163 / 8).

**Size (brotli):** threeLayer chunk 143.75 → 143.82 kB (+0.07 kB), all JS 950.75 → 950.7 kB. Budgets unchanged from #220.

**Visual parity** (harness, 1440 + 390 px; top with trains, Elevated, Street, X-ray): only storefront signboards move, by ≤0.11 % of their distance from the map centre (≤ ~22 cm at the 200 m edge). The old code placed them with 111,320 m/° while MapLibre's projection uses 111,195 m/°, so the plates now sit exactly where MapLibre draws the facades. Nothing else changed.
