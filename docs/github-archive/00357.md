At block level the 311 map still shows grid cells (`r,c` keys) instead of real tax blocks, unlike noise and crashes.

## What changes
- Migration `20261023000100_block_keyed_source_counts.sql` adds `core.tax_blocks` and `raw.source_block_cells` (with a down section).
- For `level=block` on a block-keyed source, `/api/blocks` returns one row per tax block. Other levels and sources still use the grid path. Only `311` is block-keyed so far.
- New `scripts/block-counts.ts`, called from ingest after the 311 grid ingest, rolls points to about 11 m cells each month and joins them to tax blocks in DuckDB. The blocks-geojson download moved into `block-join.ts` so two scripts share it.
- `backend.ts` parses the block rows and sums neighbourhood totals from them.
