## What
Live traffic feature module (`src/features/traffic`, `server/features/traffic`). Basic tier, **Traffic** chip off by default (`?on=traffic`).
- `GET /api/traffic`: NYC DOT Real-Time Traffic Speed Data (Socrata `i4gi-tjb9`). Each link is coloured green / yellow / red by its current speed against free-flow speed (85th percentile of its last 12 h of readings, capped at 55 mph), offset per direction and drawn under labels. Today's DOT street closures (`i6b5-j7bu`) are dashed red. Server polls every 5 min.
- `GET /api/traffic/along?line=lon,lat;…&buffer=60` = `getTrafficAlong(lineString)` for the trip agent, through the API rather than an import. Both routes are in the OpenAPI spec.
- Credits sheet: traffic covers only DOT sensor corridors.
- Daylight no longer recolours traffic, parking or transit layers, so closures stay red at night.
