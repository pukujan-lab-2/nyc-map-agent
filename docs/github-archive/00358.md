Compare mode (issue #191) needs a draggable divider between the 3D street view and a Mapillary photo. This adds only that component.

The divider drags by pointer and moves by keyboard; panes sit side by side at 560 px or wider and stack below that. Pure divider logic (clamp 10 to 90%, pointer to percent, keyboard nudge, layout choice) is in `compareSliderMath.ts` with 10 tests. Typecheck and lint pass.
