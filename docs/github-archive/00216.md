# PR #216: feat(client): typed API client and schemathesis contract test

The app's data-layer API calls were hand-typed `fetch` strings, so a renamed route or query parameter only failed at runtime, and nothing checked that the real server actually returns what `openapi.json` promises.

> **Stacked on #215** (`/api/v1` prefix). Merge #215 first; this PR's base then moves to `main`.

**What changes**
- `src/lib/api/schema.d.ts` generated from `openapi.json` by [openapi-typescript](https://github.com/openapi-ts/openapi-typescript) 7.13.0 (dev, MIT). `pnpm openapi` regenerates it; `pnpm openapi:check` (CI `api` job) fails if it is stale (`--check`).
- `src/lib/api/client.ts`: an [openapi-fetch](https://openapi-ts.dev/openapi-fetch/) 0.17.0 client (MIT, ~2 kB, one dep) plus `unwrap()`. `src/lib/datasets/backend.ts` (sources, blocks, areas, aggregate) now calls `/api/v1/*` through it with typed paths and query params; zod parsing of bodies is kept.
- New `contract` CI job: `scripts/ci/contract.sh` starts the real server (`server/node.ts`, no secrets) and runs [schemathesis](https://github.com/schemathesis/schemathesis) 4.32.3 (MIT, pip-audit clean) on every documented GET under `/api/v1`: status codes, content types, response schemas. Excluded: binary tile/model routes, POST `/agent` (LLM), `/parking*` (Overpass upstream takes >30 s).
- Contract finding fixed in the spec: `GET /traffic/along` allows a 20 000-char `line`, but Node rejects URLs over 16 KB with **431** before the app runs. 431 is now documented on all routes (not breaking per oasdiff).
- `e2e/mocks.ts` serves fixtures for both `/api/v1/*` and `/api/*`.
- `.size-limit.json` "all JS" 932 → 935 kB: openapi-fetch adds ~1.5 kB brotli (933.5 kB now).

**Verify:** contract run locally: 96 generated cases, all pass (the 431 failure happened before the spec fix). `pnpm test` 168 pass, `pnpm lint`, `knip`, `pnpm audit --audit-level high`, `pnpm licenses:check` clean.

**Unchanged:** UI components; feature modules (`src/features/*`) still call `/api/*`, which stays as an alias. Moving them is left for when UI work resumes.

**Branch protection:** `contract` is not yet required; add it after merge.

Closes #205
