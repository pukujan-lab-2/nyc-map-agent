- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/120

Since #119, noise and crashes shade real tax blocks from their BBL-keyed aggregates. Other registry sources still come from /api as ~300 m grid cells (r:c keys), which don't match the block tiles' feature ids (boro*100000+block), so at the Blocks scale on Octo they shade nothing (neighborhood scale works). Needs a BBL-keyed /api endpoint (spatial join to blocks in the ingest pipeline, as for noise/crashes) and the client using it. Also restore the noise category filter at block level.
