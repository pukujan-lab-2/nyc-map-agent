## Problem

Right after each deploy, the parking cache is empty. The first request to `/api/v1/parking` then waited for two sources: the city's licensed garages and Overpass (the OpenStreetMap query service). Overpass can take up to 40 seconds. So the first person to open parking after a deploy waited that long, and the post-deploy contract check timed out at 20 seconds (main run for a688905).

## What changes

The answer now waits for Overpass for at most 6 seconds. After that it answers with the licensed garages alone. The OpenStreetMap lots keep loading into the cache and are included from the next request on.

## How to verify

A new test makes Overpass never answer. The licensed garages still come back at once, with only the city's garages in the list. Type check and lint pass.

## What stays the same

Both sources are still cached for 24 hours, and an OpenStreetMap lot near a licensed garage still only adds its capacity.
