# Issue #204: API versioning: /api/v1 prefix with /api/* alias; openapi info.version tied to package version

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/204
- Labels: type:feat, area:api

**Problem:** the API has no version in its path and openapi.json's info.version is not tied to releases, so breaking changes cannot be signalled.
**Change:** serve routes under /api/v1 with /api/* kept as an alias; info.version comes from package.json; CI fails when oasdiff finds breaking changes without a major bump.
**Done when:** both prefixes answer identically and the CI gate is in place.
