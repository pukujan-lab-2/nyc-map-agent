Closes #278. Part of #274.

- New isolated modules: `src/lib/map/three/sun.ts` (suncalc sun for NYC, `?time=HH:MM` + optional `?date=YYYY-MM-DD` in New York time, Shadows setting, moving casters) and `src/lib/map/three/shadowLayer.ts` (one MapLibre custom layer through the shared three.js renderer).
- One DirectionalLight, castShadow, PCFSoftShadowMap, 2048 maps (1024 on coarse-pointer / <=4 cores / <=4 GB devices). Shadow camera is an ortho frustum centred on the view target, sized to the visible ground radius (60–700 m); bias -0.0004 + normalBias ~1.5 texels (no acne, no peter-panning).
- Buildings (city3d or basemap extrusions, whichever is drawn) are proxied as merged prisms that cast and receive (ShadowMaterial over MapLibre's own lighting, depth prepass so only the visible surface darkens); trees (city3d props), trains and buses (from the vehicle layer) cast; the ground receives.
- Strength and tint follow sun altitude (warm light / cool, lighter shadow at golden hour), fade out below the horizon (night look untouched), weaker and softer under cloud / fog / rain / snow. MapLibre's own light remains the ambient fill so shaded sides never go black. Daylight palette and Auto theme honour the same `?time` override.
- 'Shadows: on/off' in the Layers drawer (Advanced), default on for desktop, off on mobile / low-end.
- three.js stays behind `src/lib/map/three*` (dependency-cruiser rule widened to `src/lib/map/three/`); no deck.gl; all-JS 867.6 kB / 945 kB.
- Touches `threeLayer.ts` by 2 lines only (report casters); merges main in, no rebase.
