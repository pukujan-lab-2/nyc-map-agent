## What
Time-of-day lighting as a feature module (`src/features/daylight`), keyed to NYC sun position via suncalc.
- Basemap recolor (raster fallback dimmed via raster-brightness), setSky/setLight, building tints, lit facade windows at night, warm streetlight wash on roads. Eco mode skips the glow.
- Settings → Lighting: Auto (default) / Day / Night, persisted (`src/lib/ambient.ts`, a tiny shared store so later features never import each other).
- Generic glue reused by the next PRs: FeatureModule `TopBar` / `chip` / `PlaceSection`, MapView mounts lazy `layers.mount(map)` per flag, `on=` URL toggles for off-by-default chips.

## OSS reuse
suncalc 1.9.0 (BSD-2-Clause, 4 kB, the standard JS solar-position library). Its package.json has no licence field, so it gets a reviewed exception in scripts/check-licenses.ts.
