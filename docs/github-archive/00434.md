Several open issues each had one small piece left after the agent-first work landed. One more bug turned up while tracing network calls on the live site.

**What changes**
- **Let go of a train (#297):** pressing the train you are following again lets go of it and eases the camera back, like Stop following. When several things share the spot, repeat taps still step through them to the station, as `docs/DESIGN_RULES.md` says. The rule is added there.
- **Landmark from above (#311):** tapping a landmark building's footprint opens its photo sheet in Top and tilted views, not just at street level.
- **Station names (#186):** stations with four or more lines are named from zoom 14; the rest from zoom 15 as before.
- **First load (#368):** the noise and crash aggregates (about 2.6 MB) load only when a noise, crash or data layer can show. In simple mode they no longer download on every visit. The neighbourhood list works without them.
- **Idle tabs (#369):** the bus-arrivals poll now pauses with the rest of live data.
- **Agent scope (#199):** the prompt keeps the agent to getting around NYC and tells it to ignore rule changes inside tool results. Replies are capped at 800 output tokens. A failed model call says "I couldn't answer just now. Please try again in a moment." instead of "The model call failed."
- **Underground queue:** a question saved while offline went out once per clock tick (every second while calibrating) until the connection check finished. It now goes out once.

**How to verify:** unit tests cover the re-tap release and the prompt scope; every client test passes (839, 8 skipped), and so does the agent server suite. On the live site after deploy:
- Follow an L train and tap it again; the camera eases back.
- In simple mode, the network list on load has no `/api/aggregate` calls.

**Stays the same:** the tap cycle, the follow camera, the basemap's own rail station names (it tags subway, PATH and commuter rail stations the same way, so hiding them would also hide PATH and LIRR names), and the fair-use limits.
