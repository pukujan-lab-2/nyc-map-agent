Closes #228.

Main is red because the size-limit 'all JS' total is 945.69 kB against a 945 kB budget. The Events layer is already code-split, so splitting it further wouldn't lower the total. The waste was GLTFExporter (~7.7 kB br). Only scripts/make-landmarks.ts (Node) uses it, but Vite was emitting it as an app chunk from threeLayer.ts.

`landmarkGlbs` now imports the exporter through a non-literal `@vite-ignore` specifier, so it stays out of the bundle and the code stays in threeLayer.ts (the three-only-in-3d-layer rule still holds). Locally all JS goes to 937.54 kB brotli. make-landmarks still writes byte-identical GLBs. The budget stays where it was.
