Refs #67 (stays open until signboards are confirmed visible). Supersedes draft #98 and #140 (same storefront commits, rebased onto main after #96/#131).

**Crash fix**
- three.js now lives only in `src/lib/map/threeLayer.ts`: 3D vehicles, corner street-name signs (moved from `streetSigns.ts`, which is deleted) and storefront signboards.
- All three custom layers draw through one `WebGLRenderer` per MapLibre GL context (`sharedRenderer`). Before, each layer made its own renderer on the same context.
- Street signs no longer call `triggerRepaint()` on every frame, which had kept the map repainting forever.
- One size-limit entry for the shared chunk (125.8 kB of 130 kB; hydrants and elevated structures are in it too).
