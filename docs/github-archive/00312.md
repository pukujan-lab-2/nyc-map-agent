# Issue #312: Legends and overlapping labels should stay readable

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-23
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/312

## Problem
The user pointed at a screenshot where names and legend colors are hard to read once labels land on top of each other.

## Ask
- Legend swatches and the labels that go with them should stay readable, using a bold weight or a neon color when the map underneath is busy.
- When two labels overlap, draw one of them. Do not stack the same name twice.

This is separate from the station-name work in #186. No code in this issue.


---

**Pukujan commented, 2026-10-25**

Fixed by #445 and now live.

- A name the landmark guide already draws is no longer drawn a second time by the basemap.
- Landmark and ferry names have thicker outlines, and ferry terminal names are bold.
- In the map key, line swatches are thicker, the colour bar is taller and outlined, and "fewer / more" is in full-strength text.

Trains and buses still always draw, even when they overlap, as the owner asked.
