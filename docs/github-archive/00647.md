### Summary

When a train line is suspended and a shuttle bus replaces it, the map draws a text label "Take the T426 bus here" with no station marker under it and no station name, so it looks like it floats in the middle of nowhere. The owner also wants the map itself to say "transfer to the bus".

### Identity and Lineage

Repository Pukujan-lab/nyc-map-agent. Code: the `ends` source in `src/features/transit/TransitLayer.tsx` (label built near line 650, layer `transit-alert-end` near line 1475); the end stations come from `src/features/transit/alertFocus.ts` (`suspension`). Related: the shuttle stops drawn for the chat in `server/features/agent/mapActions.ts`.

### Acceptance Criteria

1. At each end of a suspension where a replacement bus runs, the map shows a ring marker on the station and the label "Transfer to the T426 bus at <station>".
2. Where no bus is named, the label says no trains go past that station, as now, but also with the marker.
3. A unit test covers the label text.
4. The layout bar passes at all sizes.

### Boundaries and Next Action

In scope: the marker and wording at the end stations. Out of scope: placing bus stops at street corners (the MTA's notes give corners in words only, not coordinates) and the chat's shuttle pins. Next action: add a ring layer and the station name to the label.

### Symptoms

1. **Floating label:** a text-only label sits near a line vertex with nothing marking the station.
2. **No station name:** the label says "here" but not where.
3. **Wording:** it says "Take the bus", not that this is where you change from train to bus.

### Hypotheses (unverified)

H1. A ring on the station and its name in the label make the spot readable. **Status:** unverified. **Would confirm:** the owner sees the label tied to a marked station on the same screenshot case. **Would refute:** the label still reads as detached. **Experiment:** open the A-line alert with the T426 shuttle on the live site after deploy.

### Counter-signal

The label point is the end station's own coordinate (`alertFocus.ends`), so the position is right; what is missing is a marker and a name.

### Honest Caveat

I could not reproduce the owner's screen exactly; the diagnosis comes from the code and one screenshot.

### Problems vs Gaps

Problem: an unmarked, unnamed label. Gap: no marker layer for suspension ends.
