# Issue #203: Asset version history: published_assets keyed by name+sha256 with a current pointer, plus a build asset manifest

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/203
- Labels: type:feat, area:db, area:tiles

**Problem:** core.published_assets holds one row per name (PR #193 adds one previous_* slot), so a running app build cannot be tied to the exact tile set it was built against.
**Change:** a migration into a history table keyed by (name, sha256) with a current pointer, building on #193's previous_* columns (stacked on #193 since it has not merged), plus a build-time asset manifest recording which asset versions a build uses.
**Done when:** migration up/down is reversible, publish writes history, and the build emits the manifest. Refs #193
