The 3D layer (trains, buses, hydrants, street signs, storefronts, kiosks, landmarks) ran on three.js 0.134 from 2021, which blocks the planned split of `threeLayer.ts` (#219) and every newer three.js fix. This moves it to 0.186.1 with no intended change to how anything looks.

Closes #218

## What changes

- **three 0.134.0 → 0.186.1** and `@types/three` 0.186.0.
- **Same colours.** three 0.152 started converting hex colours to linear light, so every material would render darker. `THREE.ColorManagement.enabled = false` keeps the old handling. The renderer and the atlas textures use the new `outputColorSpace` / `colorSpace` names for the same sRGB setting.
- **Same brightness.** three 0.165 removed the legacy light scale, which multiplied every light by π internally. Each ambient, hemisphere and directional light is now written as its old value × π (`LEGACY_LIGHT`).
- **Atlas shaders.** The sign, kiosk, storefront and facade materials patch the vertex shader to pick their atlas cell. three renamed the texture coordinate from `vUv` to `vMapUv`, so the patches write `vMapUv`.
- **Types.** three now ships types for the meshopt decoder, so our stub `meshopt-decoder.d.ts` is gone. The landmark GLB exporter passes the new error callback.
- **Docs.** `AI_RULES.md` names the version and the colour and light settings.

## Size

The shared 3D chunk grows from 134 to 148.6 kB compressed, so its budget moves to 150 kB, and the all-JavaScript budget moves from 1045 to 1060 kB (measured 1052.7 kB). The main bundle is unchanged: three only loads when 3D is on. The street-photo viewer (mapillary-js) keeps its own three 0.134 inside its own chunk, which is unchanged at 220.8 kB.
