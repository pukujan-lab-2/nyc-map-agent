# Issue #252: fix(voice): hands-free turn-taking cuts off speech and answers

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/252

Report: voice gets cut off when taking turns. Root causes: recognition runs with continuous=false so Chrome ends the turn on the first short pause; whole answer is spoken as one utterance (Chrome truncates/stalls long utterances ~15 s, voices-not-loaded race); no barge-in; spoken reply is the full text answer. Fix: tuned 1.3 s silence endpointing, sentence-chunked TTS queue with keep-alive, mic paused while speaking with echo-cancelled barge-in detector, short spoken summaries, clear Listening/Thinking/Speaking state.
