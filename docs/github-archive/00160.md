# Issue #160: Restrooms: show only the nearest few, not the whole city

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/160

Turning on Restrooms draws every public restroom in the city, which buries the few a person could actually walk to.

What should change: show only the closest few restrooms to the map centre (or to the person, when they share location), and update as the map moves.

Done when the Restrooms chip shows a small nearby set and the list follows the map.
