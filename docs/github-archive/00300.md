Following a vehicle and then asking how to get somewhere made the map thrash. Follow started a new quarter-second glide toward that vehicle about 15 times a second. The trip preview set the camera every frame along the new route. Both ran at once. Overhead is high enough that a heading twitch swings the whole view, and the X-ray disc sweeps with it.

Asking for directions, fitting the route, dropping to street level, or previewing the trip now takes the camera. Follow and street view let go first, and the map stops any glide already running. That release does not glide back to the view from before follow. The Stop following button still does. Tapping a vehicle stops the preview the same way, without sending the camera home, and follow then owns the view.

While follow owns the camera it sets one pose per vehicle update instead of stacking glides. A heading that flips more than 150° is ignored until that flip has stayed for four updates, so one noisy bus heading cannot spin the view.

How to verify: follow a bus or train, then ask how to get somewhere and start the preview. The follow card leaves and the preview flies the route without the view bouncing between the two. Stop following still eases back when no preview is running. Tapping a vehicle during a preview follows that vehicle.

Unchanged: drag and Esc still release follow where the camera is. The nearby X-ray size change is a separate pull request.
