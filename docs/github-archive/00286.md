# Issue #286: Ask the map tells you to go find My location on the map

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/286

Ask the map tells you to go find My location on the map when a trip starts from here.

Asking "from here" with location turned off gets a paragraph that says to tap My location on the map. That control sits in the layers sheet, and tapping it also zooms the map in. The reply should carry a Use my location button. Tapping it shares your position and asks the same question again.
