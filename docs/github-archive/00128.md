## What
Parking feature module (`src/features/parking`, `server/features/parking`). Basic tier, **Parking** chip off by default (`?on=parking`).
- `GET /api/parking`: licensed garages and lots from NYC DCWP (`w7w3-xahh`, category "Garage & Parking Lot", status Active) plus OSM `amenity=parking` via Overpass, used only to add capacity where it sits within 40 m of a DCWP site. Cached 24 h.
- Small P icons from z13; at street zoom (z17+) a raised sign standing up from the building. A tap opens a panel card with name, address, capacity (if known) and **Directions**, which sets the route end.
- Place panel: collapsed **Street parking rules** drawer for the picked block. Sources are NYC DOT parking signs (`nfid-uabd`, state-plane x/y converted with proj4) and meters (`693u-uax6`).
- `GET /api/parking/near?lon&lat[&radius]` = `findParkingNear(lngLat)` for the trip agent; `/api/parking/rules`. All in the OpenAPI spec.
- No occupancy is shown or invented, because no open live feed exists. The credits sheet says so.
