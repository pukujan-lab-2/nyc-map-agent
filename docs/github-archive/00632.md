# PR #632: fix(agent): stop offering to start a trip after a line status answer

- State: merged (2026-11-01)
- Opened by Pukujan on 2026-11-01
- Original: https://github.com/Pukujan-lab/nyc-map-agent/pull/632
- Branch `fix/629-drop-own-close` into `main`, +45 −8 in 5 files, merge commit 3d384cfeb448f500101df4c53434b2df5786c5ca

Every line status answer that planned no trip still ended by asking the rider to start one, and the new eval put a number on it: 92 of 174 trials in the baseline.

## Human outcome

A rider who asks how a line is running hears what is wrong and where, and is not offered a trip they never asked for.

## Before and after

**Before:** the app replaced the model's own "Want to start?" only when it had a follow-up of its own, which means a planned trip. A line status answer planned nothing, so the phrase went to the rider.

**After:** the route drops that phrase when nothing set a follow-up. Train trials clean went from 14.6% to 43.9% and held-out from 25.5% to 39.2%. Five trials still fail the check, all worded differently ("Want to start planning your trip?").

## Change and scope

- `server/features/agent/routes.ts`: one condition. The close that the app holds back is dropped when `closing.line` is null, and only the trip tools set that.
- `server/features/agent/ask.test.ts`: a line status answer through the route with a mocked model. The chat helper now passes empty alert feeds, so the tool runs for real instead of failing.
- `docs/eval/line-status/LEDGER.md`: the iteration row, so the next run can compare against it.

## What stays unchanged

The prompt, the tool results and the eval's checks. A planned trip still ends with the app's own follow-up in the rider's language, and a language without phrases still gets the model's question worded by the model.

## Verification

- `npx vitest run server/features/agent`: 298 tests pass, including the new one. `tsc --noEmit` and `eslint` are clean.
- `tsx scripts/eval-line-status.ts --trials 3 --sources builtin --label try-no-own-close` on LFM3, then `tsx scripts/eval-line-status-compare.ts` against the baseline run, which printed `keep: train 14.6% to 43.9%, held-out 25.5% to 39.2%`.
