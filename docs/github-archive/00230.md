# Issue #230: ci: run db:migrate in the deploy job

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/230

Prod migrations only run in nightly-ingest, so a deploy can ship code ahead of its schema. Run `pnpm db:migrate` in the deploy job before triggering the deploy.
