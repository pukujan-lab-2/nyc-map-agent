# Issue #374: Decide and state what location data we keep

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-24
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/374

The agent will know home, work and a child's school route. The project has no written rule for what location data is stored, where, or what is sent to the model provider.

## Evidence
- Saving home and work is in PR #327; where it is stored was not checked.
- The agent sends questions to a model through InferHub; whether coordinates are included was not checked.

## What is needed
- A short written policy: what is stored on the device, what reaches our server, what reaches the model provider, and for how long.
- Send the model only what an answer needs.
- A way for the user to clear saved places and history.

## Acceptance criteria
- [ ] The policy is written in the repo and shown in the app.
- [ ] Requests to the model are checked against the policy.
- [ ] Saved places can be cleared in one step.
