# Issue #56: Live MTA transit layers: subway, LIRR, Metro-North, buses

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/56

Add live MTA transit to the map, toggled from the Layers dropdown under a Transit group.

- Subway: NYCT GTFS-rt (api-endpoint.mta.info nyct/gtfs*) proxied via Hono `/api/transit/subway` (~15 s cache), decoded with gtfs-realtime-bindings. Static GTFS lines (official colours) + stations baked into `public/transit/`. Approximate train positions interpolated along shapes from trip updates. Station click opens a sheet with next arrivals by line and direction.
- LIRR (lirr/gtfs-lirr) and Metro-North (mnr/gtfs-mnr): same, separate toggles.
- Buses: Bus Time GTFS-rt vehicle positions via `/api/transit/bus`, key from `MTA_BUSTIME_KEY`; toggle hidden when the key is absent.
- Vehicles: oriented icons in 2D, extruded MapLibre bodies in 3D/street, tweened between updates, viewport-culled and capped.
- PATH: only if a reliable public GTFS-rt feed exists.
