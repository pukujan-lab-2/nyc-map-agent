# Issue #652: Run trips on OpenTripPlanner and walking routes on a self-hosted Valhalla

- State: open
- Opened by Pukujan on 2026-11-01
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/652

### Summary

Trips on the live site come from MOTIS, and walking routes come from a free public OSRM server run by FOSSGIS. The owner chose OpenTripPlanner (OTP) for trips, because step-free (wheelchair) routing and LIRR trips are on the roadmap and OTP handles both well, and a self-hosted Valhalla for walking routes. This moves both onto the VPS.

### Identity and Lineage

Repository Pukujan-lab/nyc-map-agent. OTP was the planner until the move to the VPS (#603), which shipped MOTIS without comparing the two. The OTP client (`server/features/agent/otp.ts`) and its graph build (`deploy/otp/`) are still in the repo. Related: #651, #641.

### Acceptance Criteria

1. `nyc-map-otp` runs on the VPS from a graph with subway, the five bus feeds, LIRR, Metro-North and both ferries, with live updates, and the app plans trips with it (`TRIP_PLANNER` no longer set to motis).
2. `nyc-map-valhalla` runs on the VPS, and the server's walking routes come from it, with the public OSRM server as fallback.
3. Both rebuild with one script each, documented in `deploy/README.md`.
4. A spot check of trips on the VPS against MOTIS, recorded on the pull request.

### Boundaries and Next Action

In scope: running OTP and Valhalla on the VPS and pointing the server at them. Out of scope: step-free trip search (next, OTP's wheelchair option plus Valhalla's wheelchair profile), the browser's street-view steps (still the public OSRM server), removing MOTIS (kept one week as a fallback). Next action: build both on the VPS and switch.
