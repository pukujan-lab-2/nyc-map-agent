# Issue #370: Agent-first screen: chat at the bottom, Siri-style voice, visible agent steps

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-24
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/370

The realigned product is an accessible chat and voice agent over the map, but the current screen leads with a top search bar, a small "Ask" button, and many controls. It does not feel like talking to an assistant.

## What is needed
- A chat prompt at the bottom of the map and a voice button with a live waveform (Siri-like).
- While the agent works, an "Agents working" panel shows its steps (for example Planner, Data query, Search) instead of a spinner, and a spoken line covers long waits.
- Answers in the user's language, by chat and voice.
- Technical dashboards and in-depth controls move behind advanced mode.

## Evidence
- Owner's direction, 2026-10-23, with a reference mock showing "Walk mode · live", a voice waveform and an "Agents working" panel.
- Today: a top search bar with an "Ask" button (seen at 390 px on 2026-10-23); a text skeleton while the chat loads (`src/components/ChatPanel.tsx`).

## Acceptance criteria
- [ ] The first screen is the map with a bottom chat prompt and a voice button.
- [ ] The agent's working steps are visible while it answers.
- [ ] A question asked in another language is answered in that language.
- [ ] Advanced controls are out of the default view.
