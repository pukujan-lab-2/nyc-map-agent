### Summary

The agent answers in whatever language the rider uses, but the app's buttons, labels and menus are English only, and there is no language choice at first open. For newcomers who don't read English well, this is where we are behind Google Maps, which follows the phone's language.

### Acceptance Criteria

- [ ] Main buttons and labels are available in Spanish and Chinese first (proposed)
- [ ] A language can be chosen at first open (proposed)
- [ ] Layout checks pass at small phone sizes in each language (proposed)

### Boundaries and Next Action

Out of scope: translating station and street names (they must match the signs).
Next action: list the strings on the main screens and pick the first two languages with the owner.

### Symptoms

1. **The conversation follows the rider's language; the app around it doesn't.** Buttons, labels and menus are English only, as `docs/HACKATHON_WRITEUP.md` states.
2. **The wake phrase listens for English only.**
3. **No language choice at first open**, which matters on a borrowed phone set to English.

### Hypotheses (unverified)

- (hypothesis) Translated labels fit the current layouts at 320 px wide.
  Experiment to confirm: run the existing layout checks with Spanish and Chinese labels.
