**Problem.** While following a train, the one-line strip and the first row of the stops list could name the same stop with different minutes (seen live: "2 min" on the strip, "0 min" in the list). The strip used the train's own estimate, while the list used the trip's timetable.

**What changes.** When the list starts at the strip's stop (matched by station), the strip uses that row's time. Otherwise it still uses the train's own estimate.

**How to verify.** Follow a train, open the sheet, and compare the strip's minutes with the first stop in the list.

**Stays unchanged.** Buses (the strip already used the bus trip's first call) and the list itself.
