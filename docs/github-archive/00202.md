# Issue #202: Release automation: release-please, commitlint and a PR-title check

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/202
- Labels: type:ci, area:release

**Problem:** releases, tags and CHANGELOG.md are not produced; nothing enforces conventional commits, so automated versioning cannot work.
**Change:** release-please GitHub Action with a manifest config starting at the 0.1.0 baseline (CHANGELOG.md, tags, releases), commitlint config for conventional commits, and a pr-title CI job.
**Done when:** CI runs pr-title on PRs and release-please opens a release PR on main.
