Names on the map could repeat and the map key was hard to read on a busy map (#312). With Parks or Things to do switched on, a museum the landmark guide already labels also got its own name from the basemap, so the same name showed twice. Ferry and landmark names had thin outlines that disappeared against streets.

## What changes
- Basemap place icons leave out any name the landmark guide already draws, compared case-insensitively. The filter updates when the landmark list finishes loading. (`placeFilter`, `skipPlaceNames` in `src/lib/map/places.ts`)
- Landmark and ferry names get a 2 px outline, up from 1.2 to 1.4 px. Ferry terminal names are bold.
- Map key: line swatches are 3 px instead of 2 px, the colour bar is taller and outlined, and "fewer / more" is in full-strength text.

## How to verify
- `npx vitest run src/lib/map/places.test.ts` covers the filter, with and without names to skip.
- On the live map, switch on Things to do and zoom to the Met or the Empire State Building. Each name appears once.

## Unchanged
- Trains and buses still always draw, even when they overlap. The owner asked for that on 2026-10-24.
- Station names already show once: a selected line's stop names and the general station labels never draw together.
