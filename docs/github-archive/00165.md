Closes #163.

The three-vehicles layer now loads one glTF per mode (subway, bus, rail) and draws it instanced. Each mode keeps its box stand-in until its model arrives, and if the fetch fails the box stays.

- `api/vehicle-models/[mode].ts` serves `vehicle-<mode>.glb` from Octo/R2 as `model/gltf-binary`. Any other mode returns 404. The route is in `server/app.ts`, uncompressed, and in `server/openapi.ts` / `openapi.json`.
- `api/city-tiles.ts`: `pmtilesProxy` now takes a content type, so the GLB route can reuse it.
- `threeLayer.ts`: the models use meshopt. Quantized positions are expanded to floats before they are transformed. Each model is turned Z-up with its long axis along +Y, scaled to 15.7 m (R142), 12.2 m (XD40) or 21.2 m (P32), and set on the ground.
- Credits are shown in the map attribution while 3D transit is on, and listed in `public/models/LICENSE.md`. No binaries are committed.

Models (CC BY 4.0, Sketchfab):
- Subway: "New York City Subway car Type-R142" by yarankepang, 0.3 MB.
- Bus: "SFMTA Muni New Flyer XD40" by kieranfarr, 0.07 MB. Same model MTA runs, in Muni livery.
- Rail: "Metro North P32 New Haven Livery" by Sharky, 0.3 MB. It is a locomotive and untextured. No downloadable CC LIRR or Metro-North passenger car was found.
