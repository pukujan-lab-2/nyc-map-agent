The map library we use, maplibre-gl 5.24, has a critical advisory in its HTML sanitizer, and the only fixed line is version 6. This moves the app to maplibre-gl 6.15.0 and drops the last baselined advisory, so `pnpm audit --audit-level high` now passes with an empty ignore list.

Refs #93

## What changes

- **maplibre-gl 5.24.0 → 6.15.0.** Version 6 is ESM-only and ships its map worker as a separate file. `src/lib/map/maplibreWorker.ts` points the library at that file through Vite's `?url` import; the map and the street mini-map import it.
- **Camera height.** Version 6 removed `map.transform`. A small helper, `src/lib/map/cameraTransform.ts`, reads the camera transform from its new place, and the camera-height report and street picking use it.
- **Type fixes.** Named imports instead of the removed default export, `void` on `setData` (it now returns a promise), and casts where the stricter paint and layout setter types reject our dynamic property names.
- `AI_RULES.md` names the new version and the worker setup.

## Cost

The app's main bundle grows from 498 to 507.5 kB (limit 535). The worker is a separate file of about 147 kB compressed that the browser downloads once and then caches. The total of every chunk lands about 6 kB over the old 1030 kB all-JS budget, so that one budget moves to 1045 kB; every per-chunk limit stays as it was.

- In a dev build, the map, the Closer view and the Street eye-level view all render with no console errors, and the camera height reads correctly.

## What stays the same
