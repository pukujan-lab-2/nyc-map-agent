# Issue #44: Unify the Layers dropdown: one registry-driven list, drop the classic path

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/44

The dropdown lists 'Classic layers' (Noise, Crashes, Noise + crashes) and 'Single source' (311 noise, All 311, crashes) plus 'Concern score', i.e. the same data twice. One list: each registry source once, Average / Concern score, 'Choose data sources…'. Remove view=legacy; migrate old URLs (view=legacy&layer=…, src=…) to the new state. Also rename 'Textured 3D city (Lower Manhattan + Brownstone Brooklyn, zoom in)' to 'Textured 3D city' (now citywide).
