**What broke:** after #595 removed the app env file from OpenTripPlanner, OTP would not start. Its `router-config.json` reads `${MTA_BUSTIME_KEY}` for live bus positions, and OTP stops when a referenced variable is missing. Trip search was down for about a minute on gravebuster before this was hot-fixed.

**Fix:** the `otp` service passes that one variable, `MTA_BUSTIME_KEY: ${MTA_BUSTIME_KEY:-}`, and still no `env_file`. The rest of the app's secrets stay out.

**Status on gravebuster:** already applied. OTP is up, its env holds only `JAVA_TOOL_OPTIONS` and `MTA_BUSTIME_KEY`, and it answers GraphQL. To recreate it on the host, pass `--env-file /srv/nyc-map-agent/.env` so the value resolves. CD does not recreate OTP.
