Live View (Beta) will show AR walking arrows over the phone camera. This adds the permission and sensor scaffold, behind a new flag that is off by default.

## What changes
Pure `heading.ts` (circular heading smoothing, iOS and Android compass, target bearing, the "Location accuracy: about N m" line) and `permission.ts` (idle, requesting, granted, denied, unsupported; falls back to the 2D arrow when either permission is missing). A lazy `LiveViewBeta` asks only on tap and cleans up on stop, tab hide and unmount. `RouteGuide.tsx` mounts it when the `liveviewAr` flag is on. The flag registry gains optional `owner` and `expires` fields.
