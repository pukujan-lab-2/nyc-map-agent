## What
Live weather feature module (`src/features/weather`, `server/features/weather`).
- `GET /api/weather?lat&lon`: Open-Meteo current conditions, NWS (api.weather.gov, with User-Agent) as fallback; cached 10 min per 0.05° cell. Added to the OpenAPI spec.
- Looks blend with daylight via the shared ambient store: cloudy (grey light), fog (MapLibre sky/fog), rain (raw-WebGL streaks + wet asphalt), snow (flakes + white tint). Eco mode disables particles.
- Settings → Weather: Live (default) / Clear / Off, persisted. Small icon + °F in the top bar.
- QA override `?weather=rain|fog|snow`.

## OSS reuse
No new dependencies (lucide icons, zod, Hono already in the stack). Particles are ~60 lines of WebGL, not three.js (three stays in threeLayer/streetSigns).
