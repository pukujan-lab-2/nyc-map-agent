Closes #59

- **Geometry**: `pnpm build:block-tiles` dissolves MapPLUTO 26v2 lots by borough+block into 28,783 DOF tax blocks (DuckDB spatial), simplifies with mapshaper (12%, keep-shapes) and tiles with tippecanoe (z10–16, feature id = boro*100000+block, 12 MB). `pnpm publish:block-tiles` uploads the PMTiles and the simplified GeoJSON through Octo files to R2 (`core.published_assets`), reusing the #43 publisher.
- **Serving**: `/api/block-tiles` is the same Range proxy as `/api/city-tiles` (factored into `pmtilesProxy(name)`).
- **Ingest join**: `scripts/build-aggregates.ts` tees the window's points into DuckDB (`scripts/block-join.ts`): ST_Contains against the blocks (R-tree), and street-bed points snap to the nearest block face within ~40 m (311/NYPD geocode most points onto the street). Results go to the new `marts.block_stats` (migration `20261021052000`) and the block cells of `marts.aggregates`. Last run: noise 12mo 22,515 blocks, 90d 16,600, crashes 15,553.
- **Map (Octo mode)**: `src/lib/map/blockTiles.ts` swaps the blocks source to the PMTiles; heights/choropleth via feature-state. Socrata fallback keeps the ~300 m grid.
- **Labels**: the '~300 m block' text becomes the block identity, e.g. 'Manhattan block 1015 · WEST 44 STREET / 8 AVENUE' (PlaceDetails, hover card, street view, legend, caveats).
