Closes #218. Stack migration step 1 (reports/stack-research-2026-10-21.md §5 PR1).

**Version:** three 0.134.0 → **0.186.1**, @​types/three 0.134.0 → **0.186.0** (exact pins; 0.186.0 is the newest @​types/three).

**Breaking changes fixed**
- Colour: `outputEncoding = sRGBEncoding` → `outputColorSpace = SRGBColorSpace`; canvas textures `encoding` → `colorSpace`. `ColorManagement.enabled = false` keeps the legacy colour workflow every colour here was tuned for (r152+ would otherwise treat hex colours as sRGB and darken them).
- Lights: r155+ physically correct lights (legacy mode removed in r165) → ambient/hemisphere/directional intensities × π to keep 0.134 brightness.
- Imports: `three/examples/jsm/*` → `three/addons/*` (GLTFLoader, meshopt decoder, GLTFExporter); the local meshopt `.d.ts` shim is removed (types ship now).
- Shader chunks: storefront atlas `onBeforeCompile` writes `vMapUv` (r151 renamed map UVs).
- BufferGeometry: `getX` denormalizes normalized attributes now, so `dequantize` no longer rescales (it would have shrunk quantized glTF vehicles).
- GLTFExporter.parse new signature `(input, onDone, onError, options)`.
- MapLibre renderer sharing: one `WebGLRenderer` per GL context with `resetState()` before every custom-layer render, unchanged (r163+ needs WebGL2, which MapLibre 5 provides).

**Size (brotli):** threeLayer chunk 129.2 → 143.75 kB (+14.6 kB); all JS 931.94 → 950.75 kB (+18.8 kB). Budgets raised: threeLayer 132 → 146 kB, all JS 932 → 952 kB.

**Visual parity:** harness screenshots before/after at 1440 and 390 px (top with trains, Elevated, Street, X-ray): ≤0.01 % of pixels differ by more than 24/255 (anti-aliasing edges).

Tests: 163 passed / 8 skipped (unchanged); dependency-cruiser clean; knip unchanged.
