# Issue #237: Ask from street view, and a hands-free voice mode

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/237

Add an Ask button at street level that opens the assistant as a compact, non-modal sheet. The question carries the spot as context: lat/lon, heading, nearest station and entrance, and the followed train.

Add a Hands-free toggle that runs listen, send, speak, listen until it is tapped off. It uses the existing useSpeech (Web Speech API) and turns itself off where that isn't available. The mic starts only on a tap, nothing is stored or logged, a Listening indicator is shown, and the mic stays off while the app speaks.
