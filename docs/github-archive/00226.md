# Issue #226: Events layer: NYC street fairs, markets, pop-ups, outdoor shows and Parks events

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/226

## Problem

The map has no way to show what is happening on the street: street fairs, farmers markets, pop-up shops, outdoor shows and NYC Parks events. The trip simulation's inline trip cards (approved UI plan, step 8) also need "street events and closures" near a route, and there is no events data in the app to draw on.

## What is wanted

An **Events** layer, built as a feature module on both sides:

1. **Sources (free, verified by real fetches, no scraping)**
   - NYC Open Data *NYC Permitted Event Information*, Socrata dataset `tvpp-9vvx` (historical variant `bkfu-528j`). It has event type, times and a street description, but no coordinates.
   - NYC Open Data *NYC Parks Public Events – Upcoming 14 Days*, `w3wp-dpdi` (the same feed as nycgovparks.org's events XML, whose `/xml/` path robots.txt disallows, so we use the Open Data copy).
   - Event street closures come from the permitted-events `street_closure_type` and parade / race permits. A separate closures dataset is not needed.
   - Luma and Eventbrite are noted for later only.
2. **Server**: `server/features/events/` with a Hono + zod-openapi route `GET /api/events?bbox=&from=&to=&kind=`, normalised to `{id, title, kind, start, end, location, address, source, url}`. A migration adds `core.events`, and the existing nightly ingest (gravebuster runner) refreshes it with an upsert. The route goes into `openapi.json`.
3. **Client**: `src/features/events/` behind an `events` flag. An "Events" toggle in Layers & filters, off by default, with Today / This weekend chips. Small ink pins, with a chartreuse dot when the event is happening now. A tap opens an event sheet through the public panel API.
4. **Tests**: zod parsing of saved real payloads, the route, and the client toggle.

## Done when

The PR is green in CI and `/api/events` serves this week's events once the nightly ingest has run.

Plan: NYC Map user flow and UI plan (Surface inventory → "Events layer"; Open decisions → "Which events?").
