# Issue #253: Clickable transit alerts and a Lines drawer

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/253

Alerts in the train sheet's "Alerts and detours" list are plain text, so riders can't see where a detour is on the map.

**What this asks for**
1. Clickable alerts. Tapping one flies the map to the affected stretch, dims the rest, thickens the stretch, crosses out skipped stations and draws the reroute (for example the F via the E and A) as a dashed line. A slim card shows the full text, active period, direction and affected stops. Back returns to the previous view.
2. A Lines drawer. Every subway line plus SIR as coloured bullets with a status badge (Good service, Delays, Planned work, Detour). Tap to isolate one or more lines; a row expands to its alerts, each clickable. "Show all" resets. One tap away from a labelled Lines button.

Data comes from the MTA GTFS-realtime alerts feed: informed_entity stop and route ids, plus the Mercury extension (human-readable active period, affected stations with direction).
