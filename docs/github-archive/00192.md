# Issue #192: Live View (Beta): AR walking arrows over the phone camera

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/192

**Problem.** Walking directions cannot be followed "heads-up" the way Google Maps Live View does: arrows drawn over the camera.

**What is wanted (Beta).** A full-screen rear-camera view with the route ribbon, chevrons, turn arrow and destination pin drawn on top by a transparent MapLibre map at street-level pitch, posed from geolocation (high accuracy) and device orientation (iOS permission flow and `webkitCompassHeading`, absolute alpha on Android), smoothed so it does not jitter. An honest "Location accuracy: about N m" line; above 25 m it falls back to a big 2D arrow toward the next turn plus distance. Permissions only on tap, nothing leaves the device, "Stop camera" and track stops on exit, tab hide and unmount.

Limits to state: Google's precision comes from its Visual Positioning Service (ARCore Geospatial API) for native apps; a web version cannot match it. No ARCore, WebXR-only or paid VPS SDKs.

Phase 3 of 3 of Live View (phase 1: #188).
