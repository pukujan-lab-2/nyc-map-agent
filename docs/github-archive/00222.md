Give ci, secret-scan and stack-train one shared concurrency group keyed on workflow + PR number (or ref), cancelling in progress only for pull_request events so main pushes always finish. Issue Triage also stacks a run per edit/label event on gravebuster; let a newer event on the same issue cancel the older run. No triggers or jobs removed. There is no deploy workflow today; if one is added it should never cancel in progress.
