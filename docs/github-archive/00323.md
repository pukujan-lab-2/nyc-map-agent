# Issue #323: Public restrooms are hard to find, and street view cannot show them

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-23
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/323

Public restrooms stay hard to find even with the filter on. The icons are tiny and sit under bus stops, and from the opening view only a handful show up near the centre. There is no control for the nearest restroom.

Tapping a restroom, landmark, school, storefront, or other map icon starts directions by asking for a second point. It should start from where you already are.

In street view the corner map is empty. You cannot tap a restroom on it, and you cannot see where you are standing or which way you are facing. The street also reads as a bare road, without the flat building footprints the map already knows how to draw.
