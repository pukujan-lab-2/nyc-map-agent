The registry has 10 sources and issue #12 asks for more filterable NYC datasets.

## What changes
Adds `rat-activity`, a grid source built on the DOHMH Rodent Inspection dataset (`p937-wjvj`, about 3M rows, updated daily). A fixed filter keeps only inspections that failed for rat activity, so the map counts rat signs rather than visits. It is off by default, higher is worse, and has a guide. The date window excludes future-dated rows (the data has dates as late as 2045). README table updated; tests added.

## How to verify
