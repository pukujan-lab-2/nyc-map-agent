# Issue #30: Host citywide 3D city PMTiles on R2/S3 + CDN

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/30

nyc-city.pmtiles (all five boroughs, ~82 MB: 1.08M buildings, 652k trees, 110k hydrants, 2k benches, 10k poles) is too big for git and is gitignored since #21. Build with `pnpm build:city-tiles`, upload to R2/S3 behind a CDN with Range support + CORS (Range, ETag), set `VITE_CITY_TILES_URL` in deploy env. Until then, dev machines need a local copy in public/tiles/.
