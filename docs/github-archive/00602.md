## What and why

Ask the agent "how do I get to 86 St" and it answers for one of six stations with that name, without saying which. A newcomer finds out on the wrong train. The same thing happens when speech-to-text turns "Bedford Park" into "Bedford".

This change checks the place before anything else runs, and reads it back when it is unclear: "Just to check: did you mean 86 St (1 train), or 86 St (4 5 6 trains)?" The reply ("the 1", "the second one", "yes", "no, Bedford Park Blvd") is read in code, and the question goes on with the exact place written in. The model decides none of it. The idea comes from the website copilot (a separate voice guide for forms), which reads back hard identifiers in code and proved it on test sets the code was never tuned on.

It also adds `docs/PLAN-copilot-port.md`, the plan for bringing the copilot's other safety rules here (an on-topic gate, answers only from fetched data, confirm cards before side effects, holdout tests) and for one speech server both apps share.

No issue is linked; this starts the work the plan describes.

## When it reads back

1. A trip or exit question names a place ("from … to …", "which exit … for …").
2. The place is scored against the curated landmarks and every subway station name.
3. It is read back only when several places match exactly, or only a near spelling matches ("Grand Centrl"), or speech-to-text confidence for the turn was below 0.6.
4. A clear, unique match ("Bedford Av", "Times Square", an address) is not read back, so most turns wait no longer.

The server still keeps no state. On the next turn it rebuilds the read-back from the earlier message and treats the reply as an answer only if the question in the history matches ours word for word. A reply that is really a new question ("where's the nearest restroom?") drops it.

## What changes

- `server/features/agent/readback.ts` (new): the read-back, run in `routes.ts` before the fast path and the model. A read-back answer costs no model call.
- `server/features/agent/guard.ts` (new): the copilot's yes/no rules. A hedge or a condition ("yes but…", "yes if…") is never a yes.
- `places.ts`: the station matcher honours trains in brackets, so "86 St (4 5 6 trains)" finds that station.
- `stt.ts`: `/api/stt` returns Whisper's confidence (mean token probability, 0 to 1). The agent request accepts it as `heard.confidence` (optional).
- `noModel.ts`: the fast path's "found the place you asked for" check ignores the bracketed trains.
