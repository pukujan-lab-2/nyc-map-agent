# Issue #371: Every agent answer comes with buttons that show it on the map

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-24
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/371

The product rule is show, do not tell. Today the agent can move or highlight the map, but answers do not offer specific actions the user can tap.

## What is needed
Agent replies carry structured map actions that the UI renders as buttons, for example: show the skipped stops, show the substitute bus route and where to board, show where the stuck train is, show the nearest restroom, show the exits and which way I am facing, show the crashes on this route.

## Acceptance criteria
- [ ] The agent response format includes a list of map actions.
- [ ] The chat renders them as buttons that draw on the map when tapped.
- [ ] At least restrooms, transit trouble and route crashes have working actions.
