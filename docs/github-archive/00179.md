# Issue #179: Follow train: camera rides elevated track and switches to x-ray underground

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/179

## Problem
Following a live train today keeps the camera at the same height wherever the train is. On an elevated line (the 7 in Queens, the J/M/Z over Broadway) a street-level view looks up at the tracks, and on an underground line the camera sits inside the ground with nothing to see. The existing Follow button (vehicle panel) only re-centres the map every tween step, so the camera also cuts corners on curves and jumps when the feed's predicted times change.

## What done looks like
1. **Smooth along the track.** The camera rides the route shape itself (distance along the line), eased so a new feed update never snaps it.
2. **Elevated.** Camera just behind and above the train at deck height, viaduct visible.
3. **Underground.** Automatically switch to an x-ray look: buildings faded, ground veiled, the tunnel line and stations highlighted; blend smoothly at portals.
4. **Controls.** A labelled "Stop following" button and a one-line status: line bullet, next station, minutes away.
5. **Grade from data we already ship.** Each route shape point already carries underground / at grade / elevated from OpenStreetMap `tunnel`/`bridge`/`layer` tags (scripts/build-transit.ts) plus hand-placed deck heights, so no new data file is needed.

Kept out of TransitLayer.tsx as far as possible, so it does not collide with the marker-declutter work.
