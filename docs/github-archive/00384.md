## Main findings
- Position, route ends and chat stay in page memory; position never goes into the web address. Neither our server nor Caddy logs requests.
- Saved home and work (#327) are stored with exact coordinates and no expiry, and sent with every question.

- The on-screen promise that location is sent "only for that question" (`AgentOverlay.tsx`) does not match the code.
- No one-step clear of saved places or chat. Weather and parking lookups use more precise locations than needed.
- Not checked: InferHub retention, Cloudflare logging, trip-planner logging.
