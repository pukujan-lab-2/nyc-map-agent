# Issue #257: Learn bus segment speeds and stop dwell from GTFS-rt history

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/257

Problem: the bus estimator uses fixed default speeds and dwell, so it drifts from reality on slow or fast corridors.

Proposal: mirror #214 for buses: record bus positions in the periodic observe job, compute median speed per route stop-to-stop segment by hour of week and median dwell per stop, expose it via an API, and use it in the estimator in place of defaults. Migration plus bounded storage.
