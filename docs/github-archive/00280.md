# Issue #280: Empty map tap closes the layers drawer

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-22
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/280

The Layers and filters sheet (Exploring the neighborhood, with Directions, Live trains, and the layer chips) closes when you tap the map beside it.

A tap on empty pavement, a building, or a neighborhood should leave that sheet open. Done and Show map still close it. A tap on a train or a bus still closes it and follows that vehicle. Esc still closes the top panel.

A details sheet with the layers drawer closed still closes on an empty tap.
