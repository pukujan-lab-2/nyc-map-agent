On the live site, a Spanish question for a trip tomorrow at six ended "Toca Remind me", but the answer card had already closed. The card left on screen, the trip preview with play and speed controls, had no reminder button. The same question also sent the trip to Flushing Bay at LaGuardia instead of downtown Flushing: the city's address search reads a bare neighbourhood name as a venue that shares it.

**What changes**
- The trip preview card shows Remind me, in the app language, for a trip planned for later. It saves the same calendar event as the button on the trip card. The card's "Other options" is now translated too.
- Twenty neighbourhoods newcomers ask about now resolve to their main corner and station before the address search runs. Among them are Flushing, Jackson Heights, Elmhurst, Corona, Chinatown, Sunset Park, Flatbush and Brighton Beach. A trailing ", Queens" or ", Bronx" is ignored, as ", Brooklyn" already was. Station names such as "Flushing-Main St" still match as stations.
