# Issue #206: CI: migrations up/down/up against a throwaway Postgres, failing on schema drift

- State: closed (2026-10-22)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/206
- Labels: type:ci, area:db

**Problem:** down migrations are never exercised, so a broken rollback or a non-reversible migration goes unnoticed.
**Change:** a CI job with a Postgres service container that runs every migration up, down to zero, and up again with dbmate, comparing schema dumps; any difference fails.
**Done when:** the job is green on main's migrations.
