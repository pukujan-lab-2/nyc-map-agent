# PR #535: fix: exits through a building count as street exits, so stations no longer show none

- State: merged (2026-10-27)

**Problem.** Exit help said "No street exits listed" at Hoyt-Schermerhorn Sts. The MTA lists its two exits as *Easement - Street* (stairs up through a building to the street), and our filter dropped every easement along with underground passages. Eight stations were left with no exits (A42, D24, M20, D12, 231, 235, 723, S31).

**What changes.**
- Only passages are dropped; *Easement - Street* counts as a street exit (exit help, and finding which station an entrance belongs to).
- The station card shows these as "Through a building" instead of the MTA's raw "Easement - Street".
- A test covers a station whose only exits go through buildings.

**How to verify.** Live: open Hoyt-Schermerhorn Sts exit help; it lists its exits.

**Unchanged.** The 3D entrance kits (stairs, elevators, escalators only).
