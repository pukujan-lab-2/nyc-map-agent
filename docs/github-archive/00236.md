# PR #236: feat(restrooms): shops & cafés with toilets behind an 'Include shops & cafés' toggle

**Problem.** The Restrooms layer shows only NYC public restrooms, so across most blocks the toilet a person can actually use (a café, fast-food place, bar or shop) doesn't appear on the map.

**What changes**
- **Data:** a nightly ingest (`scripts/ingest.ts`, id `place-toilets`) runs one Overpass query for NYC (wikidata Q60): `toilets=yes` on `amenity=restaurant|cafe|fast_food|bar|pub` and on `shop=*`. It writes the result into a new table, `core.place_toilets`, added by migration `20261022000200_place_toilets.sql`. If Overpass returns nothing, the run fails and keeps yesterday's rows. Data © OpenStreetMap contributors, ODbL 1.0, credited in the map attribution and in the sheet.
- **Access label:** `toilets:access=yes|permissive|public` → **Anyone**. `customers`, or no tag at all → **Customers only**, the safe reading at a business; the sheet says "Access not tagged". `private` and `no` are dropped. The ingest also reads `toilets:wheelchair`, `changing_table` / `toilets:changing_table` and `toilets:fee` / `fee`.
- **API:** a typed `GET /api/v1/place-toilets` route (zod schema, in `openapi.json`, with the deprecated `/api/` alias like every other route).
- **Client:** a lazy feature module, `src/features/place-toilets`, with its own layer and overlay chunks. While Restrooms is on, an **Include shops & cafés** chip appears right after Restrooms. It is off by default (`on=restroomShops`), and nothing is fetched until it is turned on. The marker is a calm stone-grey dot, ringed green for Anyone, shown from zoom 15 up and drawn under the blue WC discs, so public restrooms stay primary. Tapping a dot opens a sheet with the name, an Anyone / Customers only badge, ♿ where tagged, changing table and fee, a source link to the OSM object, and Directions.
- **Refuge Restrooms is not ingested.** Its API publishes no data licence: the AGPL-3.0 covers the app's code, not the data. Its records also carry no access field.

**NYC counts (live Overpass, osm_base 2026-10-22 03:17 UTC):** 845 elements → 842 places: **65 Anyone**, **777 Customers only** (115 tagged `customers`, 662 untagged). 121 are tagged wheelchair-accessible.

**How to verify:** `pnpm test`, `pnpm openapi:check`, `pnpm build:size && pnpm size`. Locally, all JS came to 939.43 kB brotlied, under the 945 kB budget. Then open `/?restrooms=1&on=restroomShops`, zoom to 15 or more and tap a grey dot.

**What stays unchanged:** public restrooms (`core.restrooms`, `/api/restrooms`) and their WC marker. `LayersDrawer.tsx` changes by one line only, which places the registered chip after Restrooms. No new dependencies. No three.js or deck.gl.
