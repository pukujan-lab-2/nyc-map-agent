# PR #640: feat(layout): menus as a left column on wide screens

- State: open

On wide screens the menu row at the top left is clipped and crowds the other controls, so the owner asked for a Google Maps style left column (#637).

## Human outcome

On a laptop or desktop (1024 px wide and up) the six menus stand in a column down the left edge with their labels, and the open menu opens beside it. Phones and tablets keep the swipeable row.

## Before and after

**Before:** one swipeable row of icons at the top left that ran under its own arrow, with panels docked below it.

**After:** a 96 px column of My day, Layers, Filters, Data, City data and Settings, each with an icon and label. The map and everything over it sit in the space beside it, so nothing overlaps the column. The dropdown opens over the map to the column's right.

## Change and scope

- `src/components/MenuRow.tsx`: the column; same test ids as the row.
- `src/pages/Index.tsx`: the page is the column plus a map area (`contain: layout`, so fixed children measure from the map area).
- `src/components/MapPanel.tsx`: left panels start at the top, since nothing sits above them now.
- `src/components/ui/switch.tsx`: switches are 44×24 px, because the layout bar found 36×20 px switches in the Layers menu.
- `src/lib/useMediaQuery.ts`: `RAIL_QUERY`.
- `e2e/menu-rail.spec.ts`: the column and its dropdowns at 1280×800 and 1024×768, and the row at 1023 px.

## What stays unchanged

Phones and small tablets, and what is inside each menu.

## Verification

Run locally against a build: 97 of 103 e2e tests pass, including the new column spec and the layout bar at all sizes. This is a draft because six existing tests still fail:

- `line-chooser.spec.ts:101` taps a map point using page coordinates; it needs the map area's offset.
- `agent.spec.ts:8` and the same `task-screens` test fail on a real problem: the chat dialog (`fixed`, z-50) now sits over the trip preview's Play button on wide screens.

Not done: those six, and `docs/DESIGN_RULES.md` and `docs/PDD.md` do not describe the wide-screen layout yet.
