# Issue #375: Show how fresh each answer's data is; say "I don't know" instead of guessing

- State: closed (2026-10-25)
- Opened by Pukujan on 2026-10-24
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/375

A closed restroom, a wrong exit or a stale disruption can strand someone. Answers need their data age and source, and the agent must not guess.

## What is needed
- Every answer shows the data's age and source (for example "MTA feed, 40 s ago" or "311 data through last month").
- Stale data is marked as stale.
- When data is missing, the agent says it does not know.
- Known limits stay visible: 311 counts are reports, not measured noise; crash data runs months behind.

## Acceptance criteria
- [ ] Transit, restroom and data answers each show a source and age.
- [ ] A test question with no data gets an "I don't know" answer, not a number.
