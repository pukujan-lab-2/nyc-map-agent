Nothing measures how often the chat misreads a subway line's alerts, so a prompt change can't be shown to help or hurt (#627, #628).

## Human outcome

A cheaper model, DeepSeek, can run a loop for hours on the owner's own machines: change one thing, replay many saved cases, and keep the change only if the numbers improve on cases it was not tuned on.

## Before and after

**Before:** one wrong A train answer was fixed by hand. On LFM3 with the prompt from #628, a 12-trial smoke run was clean 3 times out of 12: 9 replies ended with an unwanted "Want to start?", and several invented a C shuttle bus.

**After:** `tsx scripts/eval-line-status.ts` asks the agent each case several times against a recorded MTA feed and clock, scores every reply with ten rule checks, and reports clean rates for training and held-out cases. `docs/eval/line-status/` holds the handoff, the loop and a ledger.
