# Issue #59: Blocks scale: replace the ~300 m grid with real NYC tax blocks

- State: closed (2026-10-21)
- Opened by Pukujan on 2026-10-21
- Original: https://github.com/Pukujan-lab/nyc-map-agent/issues/59

The Blocks scale (`?scale=blocks`) draws a fixed 0.003° (~300 m) grid, not real city blocks.

Plan:
- Build real DCP tax-block polygons by dissolving MapPLUTO lots by borough+block (DuckDB spatial), simplify with mapshaper, tile with tippecanoe into `nyc-blocks.pmtiles`.
- Publish the tiles (and the simplified polygons used by the ingest join) through Octo files to R2, recorded in `core.published_assets`; serve the tiles same-origin through a Range proxy following the `/api/city-tiles` pattern from #43.
- Spatially join 311 noise and crash points to blocks in the ingest pipeline with DuckDB spatial; write per-block results to `marts.block_stats` and the block cells of `marts.aggregates`.
- Replace the '~300 m block' label with the block identity (borough/block number + main streets).
- Verify with `pnpm build` and headless Playwright screenshots in Octo mode.
