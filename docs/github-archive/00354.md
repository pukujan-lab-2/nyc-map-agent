Stepping along a Mapillary sequence waits for each image to load. Prefetching the next few thumbnails makes the first step of the sequence walk smoother.

## What changes
New `mapillaryPrefetch.ts` picks the next N image ids in sequence order (forward or backward), skips ids already fetched with a small recent-ids cache, and loads thumbnails. `StreetViewSheet.tsx` prefetches the next 4 on each viewer image event; errors are swallowed. `mapillary.ts` also requests the `sequence` field. 9 new tests.
