# PR #183: Subway entrance signs: station name and route bullets

Closes #182.

Each 3D subway entrance now carries a sign panel. The station name is in white bold sans on a black band, with a white rule under it. Below that are the station complex's route bullets in MTA colours: white text, black text on the yellow N Q R W, and a diamond for express-only routes (ids ending in X). Bullets sit in one row, or two rows past seven routes (Times Sq-42 St: 1 2 3 7 A C / E N Q R W S). Exit-only entrances say "Exit only".

**Data.** The sign text comes from MTA Subway Entrances and Exits (data.ny.gov `i9wp-a4ja`). `pnpm build:entrance-signs` keeps each GTFS stop's station name (`constituent_station_name`) and its complex's daytime routes, plus the exit-only entrances. The result is about 19 KB of JSON. `pnpm publish:entrance-signs` publishes it through Octo/R2, and `/api/entrance-signs` serves it (route in `server/app.ts`, `server/openapi.ts` and `openapi.json`). The file is not committed. All 485 entrance stop ids in `subway.json` match. If the file can't be fetched, signs fall back to the GTFS station name and routes. The dataset has no uptown-only or downtown-only flag, so no sign shows one.

**Rendering.** All three.js code stays in `threeLayer.ts` on the shared renderer.
- Each unique sign is one canvas texture (1024×384 for a 2.0×0.75 m panel) with mipmaps, maximum anisotropy and sRGB.
- One material and one InstancedMesh per sign are shared by all of that station's entrances. The panel is a double-sided quad on a frame between the lamp posts, and it reads correctly from both sides.
- At most 24 recent signs are cached. Older ones, and everything on `onRemove`, have their texture and material disposed. The shared quad geometry and the shared renderer are never disposed (#151).
- The old dark sign boxes are gone from the stair and elevator kits.

**Shared bullets (for #178).** `src/lib/transit/bullets.ts` holds `ROUTE_COLORS` (official line colours), `routeFace` and `drawRouteBullet(ctx, route, cx, cy, r, color?)`. The face rules match `bulletFace` on `feat/calm-map`, so the 2D live-train bullets can switch to them. `TransitLayer.tsx` is not touched. Entrances get their sign through `entranceInstances` in `model.ts`, and the subway static load in `hooks.ts` attaches the sign data.

**Budget.** All JS goes from 928 kB to 929 kB. Main after #172 is about 927.1 kB, and this adds about 1.6 kB. The shared 3D chunk is 130.4 kB against its 132 kB limit. The reasons are in `.coord/proposals/0004-entrance-signs.md`.

**Checks.** typecheck, lint, knip, tests (154 passed, including new sign and bullet tests), openapi, continuity validate and preflight, hotload_check and check_manifest.
