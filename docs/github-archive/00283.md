A question typed in the top search bar never arrives in Ask the map, and on a desktop window the bar clips it.

Ask only opened the panel. The typed text stayed in the search field, and the trip assistant (which replaced the older chat panel) never read the question that panel used to send. The details sheet stays 360px, and the phone bar already spans the screen.

Verify on a wide window: type a question that is not a highlighted place, press Ask, and see that question inside Ask the map. Press Ask with an empty field and the panel still opens on the examples. The end-to-end test covers the handoff and the wider bar.
