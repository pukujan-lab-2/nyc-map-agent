Closes #121

The Manhattan Bridge (B D N Q) and Williamsburg Bridge (J M Z) tracks were drawn as a dashed underground line at ground level, because the approaches are tunnels in GTFS/OSM.

- New `raisedTrack(sys)` builds one deck quad per shape segment wherever `trackHeightProfile` is above ground. Each quad sits at its own height, so the track ramps up from the tunnel portal, holds the bridge deck (40 m / 38 m) and descends. Viaducts use the same path, so the fixed-height `viaductPolygons`/`viaductPiers` are removed. There are no piers and the deck is narrower on bridge spans, leaving room for the bridge models.
- `splitRaised` splits the ground lines under raised track. In 3D those runs are hidden; in 2D they are drawn solid instead of dashed.
- Trains already ride the profile (unchanged).
- No new dependencies, no tile builds. Tests cover the deck heights and the no-piers-on-bridge rule.
